# 西幻文明模组

一个 Forge Minecraft 26.3 模组。玩家作为文明中的一员，见证并参与一个从荒芜星球自我演化、文明涌现、动态发展的西幻世界。

> 系统架构与主循环引擎见 `SYSTEMS.md`。本文档为领域术语与详细设定。


## 一、主循环系统（唯一引擎）

**核心架构决策**：全模组只有**一个主循环引擎**。所有"系统"——气候、天道、生物演化、文明、个人、星系——都是同一引擎的不同参数实例。万物大体相似，只需主循环 + 不同程度的微调。

**主循环（所有系统统一）**：

```
感知（感知内外状态）
  → 评估（对比需求 / 目标 / 缺口）
  → 决策（选择响应）
  → 执行（消耗资源，产生输出）
  → 反馈（环境响应，状态更新）
  → 演化（长期：组合 → 筛选 → 传播）
```

**各领域差异仅为参数微调**：

| 领域 | 系统的"身体" | 感知 | 需求 | 输出 | 频率 |
|---|---|---|---|---|---|
| 气候 | 大气格 | 温度/气压 | 趋向平衡 | 风/降水 | 每日 |
| 天道 | 星球 | 万物状态 | 自我存续 | 干预/赐福/天灾 | 每季 |
| 生物演化 | 基因池 | 环境压力 | 生存繁殖 | 性状变化 | 每代 |
| 个人 | 身体 | 自身状态 | 四层需求 | 行为 | 每分 |
| 国家 | 城邦 | 内外局势 | 国运/稳定 | 政策/战争 | 每月 |
| 星系 | 天体 | 质量分布 | 能量最低 | 运动 | 每帧 |

**每个系统的定义只需五件事**：
1. 由什么组成（组件）
2. 感知什么（输入）
3. 有什么需求（驱动）
4. 能输出什么（行为）
5. 多久跑一次（频率）

**统一的健康指标**：运（稳定度）
**统一的失败模式**：内乱（内部失调）/ 外患（外部侵扰）
**统一的演化机制**：组合 → 筛选 → 传播


## 二、元系统（主循环的通用属性）

**运（Fortune）**：
贯穿所有层级的通用系统属性——系统稳定度/气数。可施加于个人、社区、国家、星球、星系、物种等任意层级。运高的系统发展顺、抗打击强；运低的系统易内乱外患。
- 形态：一个分布 / 一种倾向，非单一数值
- 来源：天生、行为累积、外部赋予、信仰等
- 聚合：各层级运的关系（个体聚合 vs 独立计算）按语境决定
- 可转移、可被夺取
- 可被特殊方法观测

**内乱 / 外患（Universal Failure Modes）**：
任何系统都可能因两种方式失衡：
- 内乱（内部失调）：系统内部组件失序
  - 国家：叛乱、权力斗争、腐败
  - 生物：内部病变、免疫失调、器官衰竭
  - 个人：精神崩溃、身体失调、欲望失控
- 外患（外部侵扰）：外部力量入侵
  - 国家：战争、侵略、经济制裁
  - 生物：病毒、细菌、寄生虫入侵
  - 个人：受伤、中毒、诅咒
疾病 = 生物层面的内乱/外患，与国家的动乱、战争的入侵是同一套模型的缩放。

**道（Dao）**：
每个物种/类属拥有自己的道——人道、鸡道等。道是该类属集体气运的载体，具有自我存续倾向（与天道自我存续同类逻辑）。
- 例：王朝末年国运衰微时，人道便会动用自身气运诞生天才，以重建或新建秩序
- 层级：天道（星球/星系）→ 国运（国家）→ 道（物种/类属）→ 个体运。各层相互影响
- 奖惩：道对个体的奖惩取决于道的性格
- 归属：个体出生即属于某道，可通过**转基因**（基因改造跨物种）或**夺舍**（意识占据他者身体）改变所属的道
- 交互：道与道之间存在交互（如资源竞争）

**玩家 = 一个国家**：玩家同样拥有内乱（精神/身体/欲望）与外患（敌人/环境/诅咒），同样受运影响。

**天道（World Will）**：
星球级、星系级的"意志实体"，是主循环在星球/星系层级的实例，运作类似国家实体。
- 独立意志，但与世界万物相互影响——宏观与微观互联
- 有性格，由该层级的状态塑造
- 目标：至少包含自我存续——维护星球/星系平衡，星球即其身体，崩溃则天道死亡
- 受世界事件与信仰影响，也会主动干预世界（降天灾、赐祝福、影响国运）

**国运（National Fortune）**：
国家实体的运。当某一形象被某国大多数人认同时，变为该国国运的形象（图腾/神/符号）。
- 计算：由国民幸福度、生活水平、安定度、文化认同等加权得出，是该国总体数值的体现
- 影响：经济发展速度、社会稳定、战争胜负、天灾概率、人才涌现等
- 因果双向：国运既是结果也是影响因子
- 可被操纵：君王治国、宗教仪式、献祭、英雄事迹等均可影响国运


## 三、世界基础

### 3.1 世界生成

**世界生成阶段（World Genesis）**：
模组启动时的迭代模拟阶段：荒芜星球 → 地貌与物种协同演化 → 文明萌芽与发展。玩家可设定投放触发条件和自身出身，迭代到目标时刻后以身份投放。可视迭代——玩家在地图界面观看大陆漂移、山脉隆起、河流冲刷的动态过程。投放后世界继续演化，时间尺度切换为 24 游戏日 = 1 年。

**世界时间尺度（World Time Scale）**：
- 生成阶段：快速迭代，压缩地质/生物/文明时间
- 游戏阶段：24 游戏日 = 1 年，实时演化

**文明灭绝（Civilization Extinction）**：
文明在世界生成阶段可能灭绝。灭绝后建筑群缓慢变为遗迹，最终完全消失。

**世界参数（World Parameters）**：
可调参数（后续优化阶段实现）：世界大小、魔力浓度、文明数量上限、种子等。

**投放触发条件（Insertion Trigger）**：
玩家在世界生成前可选的配置：
- 最先进文明到达某个时代时触发投放
- 玩家自身出身的文明时代
- 都不选则全随机演化 + 随机投放
_Avoid_: 文明发展上限

**玩家出身身份（Player Origin）**：
- 生出来（Born）：作为某文明/城邦的新生儿降临
- 被召唤（Summoned）：被某种仪式/魔法召唤而来
- 穿越（Transmigrated）：从外部世界降临
每个身份影响初始资源/装备、NPC 对玩家的初始态度、游戏目标。仅可选择出身文明，不可选具体出生点。高等文明可能生在贫民窟，低等文明可能生在富人家。

**地质地貌演化（Geological Evolution）**：
可视迭代，粗中有细。在球面拓扑上模拟板块漂移、山脉隆起、河流冲刷并行演进。视觉上沉浸，内部可简化计算。因在球面生成，双向环绕天然连续无缝。地形是地质模拟的产物，非噪声叠加。

**地貌-物种交替周期（Geo-Bio Cycle）**：
地貌演化与物种演化粗粒度交替推进。地貌先变，生物后响应，每轮有滞后性。

**物种演化（Species Evolution）**：
采用特质模块化演化：体型、运动方式、食性、防御机制、社会性、体温、感知、生殖等特质模块自由组合变异。环境作为筛选器——不适应的个体被自然淘汰。不用固定物种池，也不随机自由生成。

**生物建模（Creature Modeling）**：
模块化拼装模型。身体基础类型（四足/两足/蛇形/飞翼等）为底，特质模块叠加子模型（角、翼、尾、甲片）。支撑杂交和驯化等遗传玩法。
_技术选型待定_：GeckoLib 等动画库需确认 26.3 + Forge 可用性后再定，或用替代方案。

**文明萌芽（Civilization Emergence）**：
类人生物经物种演化达到智力阈值后，触发部落产生。部落通过自然消耗 + 需求催生逐步成长为城邦，城邦聚合为文明。

**文明选址（Civilization Site Selection）**：
文明/城邦根据地形逻辑自动选址——倾向于河流、资源、魔力节点附近，避开悬崖等不可建区域。

**时代与科技（Era & Technology）**：
双轨并行——科技线（石器→青铜→铁器→火药→蒸汽→……）和魔力线各自独立发展。同一"铁器时代"，两个文明的魔法发展水平可以天差地别。主干科技有方向约束（不可跳级），具体节奏由需求驱动。

**科技体系（Technology）**：
- 发展路径：现实向科技树（工具→机械→蒸汽→电气→工业→信息），同时可走出非现实路径（魔法驱动的机械、符文自动机等）
- 发展条件：资源、人才、知识积累——与魔法一样靠技能传承（关键技师死亡可导致科技树退行）
- 魔法-科技渗透与竞争：两者互相渗透（魔法机械、附魔工程），也互相竞争（火器 vs 火球术），此消彼长


### 3.2 环境系统

**气象水文系统（Weather & Hydrology）**：
覆盖降雨/降雪、温度、风力、洋流、河流、地下水、季节循环。影响农业、疾病传播、生物分布、文明发展。由气候模拟驱动。

模拟粒度：区域网格（多气候区独立天气） + 逐格模拟（每区块独立天气/降水/温度） + 粒子级模拟（粗粒度大气/洋流）。三层结合，成本随玩家距离递减。

三层结构：
- **粒子级（粗）**：把世界地图分成大网格单元（如 64×64 区块一格），每个格是一个"粒子"，携带温度、气压、湿度、速度向量。按简化物理规则运动与交换：热空气上升、高压流向低压、湿空气遇冷凝结、洋流随风场、海陆热力差异驱动风向。只有几百个格，跑最疏（游戏内每日一次）
- **区域网格**：接收粒子级传导的温度/湿度/气压基准值，按区域细分气候，叠加地形修正（海拔、山脉雨影）
- **逐格模拟**：仅在玩家附近热加载区运行，每区块实时天气/降水落地/径流

传导方向：粒子级 → 区域网格 → 逐格模拟。冷区仅保留粒子级+区域网格粗结果，热区推演逐格细节。

模拟机制：简化物理模拟 + 事件驱动。平时不持续逐 tick 计算，仅当区域被加载（玩家附近）或气象影响文明/生物（事件触发）时才计算。

**星球大小（Planet Size）**：
世界为一整个可环球航行的星球——双向环绕（东西向与南北向均环绕，无世界边界）。玩家开局可选星球大小（小/中/大）。大小决定文明扩张空间、地理隔离度、魔力/资源分布密度。具体尺度待定。

**位面结构（Plane Structure）**：
- **主世界**：地表文明所在。双向环绕的球面。向下挖掘依次进入地狱层
- **地狱（中心层）**：主世界地心。向下穿越重力临界点后反向——进入另一片地狱，再向上到达主世界（球面对侧）
- **末地（神明世界/悬浮层）**：悬浮于主世界上空，到达300格高度前不可见。无主岛，改为多核心岛屿，即核心文明体系的神明居所。神明依靠吸收信仰获得力量，神明世界的架构推演与人类文明类似。神与人是不同物种，但人类修习魔法可达到神明力量的高度。末地与主世界头对头——主世界进入末地后位于末地最高处，掉入末地虚空即进入宇宙空间

**多位面系统（Multi-plane System）**：
除主世界/地狱/末地外，存在多种位面：
- **元素位面**：火元素界、水元素界等——单一元素浓度极高的世界
- **精神位面**：意识海/冥想进入的抽象空间
- **亡魂位面**：灵魂、死灵元素所在的领域

**宇宙空间（Cosmic Space）**：
末地掉入虚空即进入宇宙空间。宇宙空间中存在其他星体系统——多行星系、恒星、黑洞等。大多数星体不宜居（无生命），但可前往。多星体系统构成庞大星群。

玩家能力：星际航行（魔法船/传送阵等载具待定）、登星探索（宜居星球可能存在生命/文明）、太空生存（氧气、重力、温度需求，需装备或魔法）、星体交互（采矿、引力、黑洞危险）、文明星际化（高级文明可殖民其他星球）。

星体系统程序生成。生成规则：恒星类型（红矮星/黄矮星/蓝巨星/黑洞等）→ 行星围绕（宜居带计算）→ 卫星/小行星带。宜居判定依据恒星类型、轨道距离、大气、魔力浓度。星球分野：宜居星球（可能有生命/文明）、非宜居星球（无生命但可前往）。

**星际文明规则（Interstellar Civilization）**：
文明是否发展出星际航行能力由其自身演化路径自然决定——无预设门槛，魔法线或科技线自然推进到可上天的阶段才可能星际化。文明可能永远卡死在地表。星际文明间的交互同样自然涌现——不预设星际外交/贸易/战争规则，不同星球文明各自演化，能否相遇取决于各自发展轨迹。

**无缝维度切换（Seamless Plane Transition）**：
完全无缝——无加载屏幕、无传送门，玩家走到特定高度/边界自然过渡（如主世界升至300格进入末地、末地掉入虚空进入宇宙空间）。切换中玩家保持移动与动量，环境自然渐变。实现为引擎级难题（需边界处同时呈现两层世界或自定义过渡渲染）。

**边境环绕（Border Wrap-around）**：
玩家到达边境时被无缝传送到另一侧，实现"星球"效果。

**法则系统（Laws System）**：
法则是对已有各系统的一层开关/修饰器（配置层，非新引擎），决定一个星系里"什么可能、什么不可能"：

| 法则类别 | 控制系统 | 例子 |
|---|---|---|
| 物理法则 | 地形/气候/重力 | 高重力→生物矮壮、飞行难 |
| 魔法法则 | 魔力/元素/符文 | 无魔法星系→魔法线整条封死 |
| 科技法则 | 科技树 | 无科技星系→只能走魔法 |
| 生命法则 | 物种演化/生命周期 | 繁殖快→人口爆炸；寿命长→保守 |
| 元素法则 | 26元素存在性与交互 | 无"火"元素→火系魔法不存在 |

层级：
- **星系法则**：决定哪些法则存在（可缺失）。作用于星系内所有星球
- **星球子法则**：在星系法则之上**额外开启 / 调整**某几条，**不能关闭**。"调整"指参数调整（如某星球火元素极度活跃）
- **根本法则**：某法则在星系内多数星球都存在 → 升格为星系根本法则
- **平衡**：法则少 → 发展速度更快（模拟负担小、路径少），但缺失的法则无法发展
- **主世界**：全法则星球——所有系统全开，发展较慢；最大的星球；拥有完整地狱与末地


### 3.3 加载系统

**热加载（Hot Loading）**：
玩家附近区域：完整运行四层 AI、建筑生命周期、气候模拟、实体物理。高开销。

**冷加载（Cold Loading）**：
玩家未加载或已离开的区域：仅运行长周期决策层 + 抽象资源池模拟，不做实体物理/寻路/渲染。

**冷热加载切换（Hot/Cold Transition）**：
区域在玩家进入/离开时动态切换热/冷状态。进入时从冷状态数据恢复并补齐细节；离开时从热状态降级为冷状态并压缩存储。保证 10万+ NPC 性能。

**加载层级（Loading Tiers）**：
- 热：玩家附近（如 8 区块内）——完整模拟（四层 AI、建筑生命周期、气候逐格、实体物理）。内部再分层：
  - 视野层：玩家直接看到的区域——完整 AI + 渲染 + 物理
  - 邻近层：视野外但近——完整 AI，无渲染/轻物理
  - 过渡层：热区边缘——AI 降级，准备转温
- 温：中等距离（如 8-24 区块）——部分模拟（短周期+长周期，无逐格细节）
- 冷：距离之外/已离开——仅长周期 + 抽象资源池
区域判定综合使用距离半径 + 文明/城邦边界（城邦范围整体不因玩家瞬移而瞬间卸载）。

**世界生成时序（World Gen Timing）**：
混合。世界生成阶段跑完全局概览（大陆形状、气候、文明分布、文明选址），文明附近和关键区域预生成地形细节，荒野随玩家探索按需生成。冷区文明模拟所需的地形概貌在概览阶段已具备。

**多人加载（Multiplayer Loading）**：
共享热区——多个玩家的热区合并为一个更大的热区。重叠区域按最高级别计算。共享热区省同步但热区范围大，需权衡。

**数据持久化（Persistence）**：
混合。近期离开的区域压缩后留内存（热冷切换快速），久远区域落盘。保证世界持续演化、历史痕迹留存、跨会话一致。存档随星球大小增长。

**瞬移拉热（Teleport Hot-loading）**：
渐进生成 + 拉热优先级。玩家瞬移后先出概貌（地形、建筑轮廓），细节逐步补齐（NPC 逐个出现）。拉热顺序：玩家落点及视野内优先，再向外扩展。避免传送瞬间卡顿。


## 四、生命

### 4.1 植物学

**植物系统（Botany）**：
覆盖可种植作物（对接食物系统）、野外植物生态分布与演化、魔法植物（炼金/魔药原料）、植物-元素交互、玩家/NPC 植物活动（种植、采集、嫁接、杂交）、植物杂交与驯化。

**植物生长条件（Plant Growth Conditions）**：
土壤、水分、阳光为基础。魔力浓度、元素亲和、海拔/气压、菌群/共生关系、季节/气候带、人工干预（灌溉、施肥、魔法催长）均影响生长。自然选择决定植物分布。

植物特质模块与动物统一设计。杂交与驯化机制同动物一致。

**植物杂交（Plant Hybridization）**：
- 自然杂交：相邻同科植物自然授粉产生混种
- 人工授粉：玩家/NPC 主动选择两株植物进行花粉转移
- 嫁接：不同植物枝干连接，产物混合特性
- 魔力诱导：用特定元素符文影响植株→诱发变异

**植物演化（Plant Evolution）**：
与动物演化机制一致——特质模块 + 环境筛选，不模拟固定进化链。环境作为筛选器，不适应的植株被自然淘汰。演化结果由气候、土壤、魔力浓度、元素分布共同决定。植物-元素交互：植物吸收环境元素，部分魔法植物可提纯/转化魔力。

**植物驯化（Plant Domestication）**：
野生植物采集→反复选育优良个体→多代后稳定成驯化品种。驯化品种产量更高、抗病性更强，但野外生存能力下降。不可简单通过种植即视为驯化。

**魔法植物（Magic Plants）**：
与普通植物的区别：含有元素亲和（额外吸收魔力/特定元素）、可做炼金材料、部分品种只能野外采集不可种植、需要特定魔力环境才能生长、有独特魔法效果（发光、散发元素波动、吸引/排斥特定生物）。


### 4.2 疾病

**疾病系统（Disease System）**：
统一覆盖植物、动物、NPC。疾病有传播途径（空气/接触/水/食物/魔力）、潜伏期、症状、致死率。影响实体属性数值（体质下降、精神压力上升等），可被治愈或被魔法干预。文明可通过卫生、医疗设施、魔法研究降低疾病影响。

疾病产生来源：自然环境滋生（沼泽瘴气、腐烂尸体）、生物携带传播（老鼠→鼠疫、NPC→流感）、魔法诱发（魔力污染、诅咒疾病）、文明产物（过度拥挤→卫生崩溃→瘟疫）、物种演化自然出现（细菌/病毒演化出新变种）。

疾病治疗：自然愈合（体质自行恢复）、草药治疗（植物学产出的药材）、魔法治疗（治愈类魔法：疗愈/恩泽/涤魂）、医术/手术（文明科技发展后）、隔离+卫生（阻断传播途径）。

### 4.3 NPC 与智能

**文明实体（Civilization Entity）**：
文明本身作为不可直接交互的数据实体。不做决策不执行行为——纯数据容器 + 事件路由。存储人口统计、科技/魔法树状态、城邦间关系缓存、建筑登记、经济账本。权力中心通过它广播事件，NPC 通过它读取城邦状态。
_Avoid_: 文明调度层、全局控制器

**NPC**：
世界中的智能实体，拥有四层 AI 调度，可隶属于城邦/文明。

**四层 AI 架构（Four-layer AI）**：
- **即时反应层**：寻路、战斗（近战/远程/魔法）、逃跑、拾取、闪避、环境危险反应、跟随、战斗切装备、开门关门、短距警示呐喊、状态应急反应、跳跃攀爬。逐帧至每秒数次。仅玩家附近 NPC 激活。
- **短周期行为层**：工作、饮食、睡眠、交易、社交、娱乐、教育、维护、宗教祭祀、冥想修炼、符文感知练习、魔力采集恢复、附魔制作、炼金调配、魔法仪式、传授魔法。几秒一次。仅玩家附近 NPC 激活。
- **长周期决策层**：婚嫁、迁徙、转行、收徒拜师、触发反抗暴动、创立权力中心、建造新房扩建、承诺效忠。几分钟一次。全部 10万+ NPC 激活。
- **交互外壳层**：打招呼寒暄、回答询问、口述历史传闻、交易对话、任务发布接取、情感表达、告别语、自由对话。按需触发，仅当前交互 NPC 激活。自由对话使用内嵌 100-160M LLM，打字时异步推理，300ms-1s 延迟模拟拟人思考。
跨层通信：事件广播（Event Bus），非状态轮询。视距外 NPC 仅运行长周期层——这是 10万+ NPC 的核心优化策略。
_Avoid_: 统一 AI 系统、行为树

**事件广播（Event Bus）**：
跨层通信机制。长周期决策通过发布事件通知低层响应，松耦合。
_Avoid_: 状态标记轮询、直接调用

**拼接实体模型（Composite Entity）**：
一个生物由多个子实体组成：头部、躯干、左臂/右臂、左腿/右腿、尾巴等。每个子实体是标准 Forge Entity，独立拥有血量、状态、受击判定。部位可被攻击、受损、脱落、再生（取决于物种）。头部摧毁→直接死亡。断尾→尾巴实体死亡脱离。缺眼→视力属性降低。NPC 和世界生物统一使用此模型。零自定义渲染代码——引擎按标准流程渲染每个子实体。性能代价：NPC 总数 × 子实体数，大多数随父实体在长周期层静默。

**NPC 属性（NPC Attributes）**：
- 基本：姓名、性别、年龄
- 身体：身高、体型、力量、敏捷、体质、颜值
- 心智：智力、感知力、学识
- 性格：内/外向、勤/惰、勇/懦、好奇/保守、利己/利他、秩序/自由、传统/激进
- 爱好：有权重的兴趣列表
- 技能：对应工种的能力值
- 关系：家庭、朋友、仇人、效忠的权力中心
- 记忆：经历过的重要事件
- 状态：饥饿、疲劳、心情、健康、精神压力
- 经济：财产
- 社交：声望、煽动力/领导力、口才/谈判力
- 驱动：野心/人生目标
- 天赋：天赋/缺陷（天生盲、过目不忘等）
- 魔法维：元素亲和（各元素天赋与亲和度）、精神海容量（感知/速率/掌控）、意识海容量（能耗/威力）、符文知识（认识的符文 + 各符文熟练度）、魔法阶段（0-25 级进度）、法术库（掌握的已验证法术）
_Avoid_: 社会阶层

**NPC 生命周期（NPC Lifecycle）**：
全模拟。出生 → 婴儿 → 儿童 → 青少年 → 成年 → 中年 → 老年。每阶段属性值随年龄变化。伴侣非必经阶段，若存在则通过属性兼容/需求拉动/社群干预/事件触发自然匹配。死亡由属性数值判定（疾病、损伤、衰老综合影响身体各项属性，降至阈值则死亡），非固定年龄或纯概率判定。

**NPC 记忆系统（NPC Memory System）**：
存储范围：个人经历事件、人际关系事件、技能/知识、城邦大事件、传闻/听说。混合存储——重要记忆存完整细节 + 事件日志引用，一般记忆仅存引用，需要时从日志反查。

衰减与遗忘：记忆随时间衰减权重，不重要事件淡化快、创伤类刻骨铭心、重大事件永不遗忘。低权重记忆定期清除。每个 NPC 配记忆数量上限，超限删除最旧低权重条目。

**NPC 属性增长（NPC Attribute Growth）**：
- 使用增长：从事相关活动→对应属性/技能值增长
- 年龄自然升降：力量等身体素质随年龄段起伏，心智等属性随年龄缓涨
- 教育加速：师徒/学院传授→技能增长速度高于自学
- 事件触动：经历重大事件→对应属性产生变化
- 天赋限制：每项属性有天生上限，努力只影响到达上限的速度
_Avoid_: 经验值系统、等级

**NPC 战斗行为（NPC Combat Behavior）**：
- 目标选择：最弱者优先/最有威胁优先/权力中心指令目标/保护在意之人
- 部位选择：头部（致命）、手臂（缴械）、腿部（限制移动）
- 逃跑条件：血量低于阈值、目睹队友死亡、战力评估劣势过大
- 战术协同：老兵带民兵、包围、佯攻侧翼
- 武器/魔法切换：近战被压制→切远程、法力耗尽→切近战

**NPC 交易（NPC Trading）**：
多机制并行。市场竞价（城邦集市，价格供需浮动）、双边谈判（一对一讨价还价，受口才/关系值影响）、以物易物自主演进为货币体系、行会中介（同行业大宗交易通道）。
_Avoid_: 单一交易模式、固定货币

**NPC 社交（NPC Social Interaction）**：
驱动因素：空间碰面（邻居/同事）、事件共历、兴趣匹配、利益连带、性格兼容/排斥、口述传播、血缘亲戚、师徒纽带、债务/恩情、宗教聚会、行业竞争、情敌/三角、犯罪/受害、赞助/庇护、救命恩情、同乡移民、同龄群体。

新增模式：
- **群体动力学**：多人→多人交互。游行、围观、公共审判、集体恐慌、节日聚会。非一对一半径。
- **信任累积/背叛**：长期合作→信任值累积→背叛→后果链。非简单关系值增减。
- **秘密/阴谋**：多个 NPC 私下协调行动（推翻权力中心、囤积物资）。长周期隐藏协调，非事件驱动。

玩家作为社交图谱中的一员自然接入。NPC 对玩家的态度由社交图谱中的位置和经历自然推导，无需独立态度系统。
_Avoid_: 独立玩家态度系统


### 4.4 NPC 角色分化

**角色分化（Role Differentiation）**：
NPC 的社会角色不由预设职业决定，而是由文明所处阶段的资源/需求状态自动涌现。多条并行路径：
- 需求缺口 + 个体响应：缺口累积→NPC 尝试填补→高效者留下→专职化
- 权力中心委派：权力中心主动扩张→指派 NPC 转业→强制分化
- 工具/资产驱动：个体攒够资本→购入生产资料→自然成为专职工匠
- 学徒继承：技能持有者收徒→徒弟独立→行业扩散
- 贸易机会拉动：邻城需求→本城邦 NPC 看到利润→主动转行
- 危机应激：外部压力→临时转行（民兵、抢修队）→可能永久化
- 文化模因：观察成功者→模仿→阶层自然膨胀

**角色匹配（Role Matching）**：
有主职和无主职并行。NPC 拥有多个有权重的爱好/兴趣，受社会因素影响发展。岗位匹配时双向选择：
- 招募方优先高数值 + 社会因素加权
- NPC 选择高数值 × 兴趣占比 + 社会因素加权
社会因素加权包含：文化氛围、家庭情况、岗位缺口、特殊工种加分（智力/颜值/力量/身高等）。
长期从事某一工种后被打上主职标签。
_Avoid_: 职业系统、预设职业、职业树

**技能传承（Skill Inheritance）**：
关键技能的代际传承决定科技树的存续。当某项技术无人掌握，对应科技树节点退行。留存书面资料可加速恢复进度。只要后续科技的前置节点仍在，科技树仍可继续推进。技能可通过学徒制、家庭传承、学院制等多渠道传递。
_Avoid_: 科技解锁即永久

**角色消亡（Role Obsolescence）**：
当某一工种不再被社会需要，持有该主职标签的 NPC 根据个体性格做出不同反应——寻找新出路、主动转行、或死磕到底。
_Avoid_: 强制转职

**角色诞生（Role Emergence）**：
当一个工种首次在某个城邦/文明中出现并被规律化（多个 NPC 稳定从事），系统正式注册该角色类型。后续可触发：对应权力中心萌芽、文化模因传播、外部城邦感知该城邦具备相关产出能力。
_Avoid_: 预设角色列表

**需求体系（Demand System）**：
驱动角色分化的四层需求，外加魔法维度：
- 生存需求：食物、水源、住所
- 安全需求：防御、治安
- 社会需求：交易、娱乐、信仰
- 发展需求：工具、科技、扩张
- 魔法维度：与上述四层交织，催生魔法相关角色


## 五、文明

### 5.1 文明与城邦

**文明（Civilization）**：
由多个城邦组成的高级社会单元，有一个中心城邦，具备自我发展能力。
_Avoid_: 国家、势力、种族

**城邦（City-state）**：
隶属于某个文明，是 NPC 生存和互动的空间容器。一个文明可拥有多个城邦。
_Avoid_: 城镇、据点、聚落

**中心城邦（Capital City-state）**：
每个文明唯一的政治中心城邦。

**城邦基础数据（City-state Data）**：
- 人口（总数 + 年龄分布）
- 资源池
- 经济（产出能力、贸易路线、货币体系、市场价格、产业分布）
- 权力中心列表（名称/内部结构/动态权重）
- 科技树（节点进度 + 区间判断，非硬性解锁）
- 魔法树（节点进度 + 区间判断）
- 城邦间关系（多维交织：贸易依存/文化渗透/军事对峙/历史渊源/外交条约/资源互锁）
- 当前需求缺口列表
- 建筑列表 + 各自状态
- 长期决议（权力中心拉锯的持久化产物，文明成熟后可对外抽象为"法律"）

**权力中心（Power Center）**：
由需求催生，从社会群体中涌现的决策力量。拥有名称（创始人/性质）、内部治理结构、动态权重。多个权力中心并存，互相拉锯，权重随事件压力实时漂移。高度集权时可能只剩一个。无预设生命周期，权重跌到零是拉锯的自然结果。
_Avoid_: 政体、政府类型、制度切换

**决策制度（Governance）**：
不由预设政体决定，而是由文明内部多个权力中心按动态权重瞬时平衡形成。制度是演变的结果，不是切换的目标。

**法律（Law）**：
权力中心拉锯产生的长时效决议。不设独立法律引擎，底层执行依旧走权力中心+关系+需求体系。文明成熟后长期决议可对外抽象为法律条文供玩家/NPC 感知。
_Avoid_: 法典系统、法律引擎

**魔力资源（Mana Resource）**：
以魔力节点、可采矿脉、区域自然回复三种形态存在于地图中，非生物掉落。
_Avoid_: 魔力水晶、魔石

**魔法能力（Magic Aptitude）**：
NPC 可通过天赋出生或后期学习获得。特定条件下整个文明可能未发展出魔法体系。

**精神海 / 意识海（Mental Sea / Consciousness Sea）**：
每个人的精神与意识形态各异（如森林无尽的叶子、王城无穷的砖瓦），后经统合形成最高效形态——精神海为无边无际的海洋（凝结魔法聚成的水滴），代表魔法下限，决定感知能力、速率与掌控。意识海为无边无际的沙海（压制水滴缩成沙粒），代表魔法上限，决定能耗与威力。符文感知需通过精神海→意识海的攀升过程。避世隐居的魔法师仍保留自己独特的精神/意识形态。通过冥想拓展。

【详解】
早期被称为精神世界与意识世界。人类接触魔法的最初期，幻想的场景千奇百怪，也发生过各种灾难：构建的场景过于庞杂导致细节被忘记变得不稳定，最终承载在其中的"实物"魔法能量全部溢出，重则可能导致死亡（也可以主动动摇场景以自爆）；塑想的"实物"各不相同用来装饰一栋构建出的庄园，这样的场景只能承载有限的"实物"，一旦出现不和谐的物品就会导致整合幻想场景崩塌，其中所承载的魔法能量也随之溢出（但这种幻想方法非常好记且清晰明确，很适合那些天赋本就不高的寻常魔法师来使用）；还曾有人迷失在自己构建的美好幻想中，更甚有人进入到别人构建的世界中没能及时出来或被困住导致随着别人的灵魂一起死去。

因此随着人类的发展法师们的交流，一种统合了的更高效的幻想方法被视为每个魔法师的基础：【塑想】的"实物"要求：结构简单、数量多、形态小有区别。【构建】的场景要求：容量大、形态荒芜。这种形态的展现可以辅以心无杂念的冥想，而不是为一些花哨的细节耗费心神。为此构建一片大地承载水滴，构建一片戈壁承载沙粒，被发扬与普及，之后所谓精神世界也逐渐开始被称为精神海与意识海。

- 【精神海】：无边无际的海洋，凝结魔法聚成的水滴。海洋的边界可以被拓展，是能够承载魔法元素多少的体现，和感知能力的强化，更强的感知能力也让冥想循环更有效率。在冥想中也能借助感知的第三人称效果探查周围环境。其中的海水就是捕捉的元素能量，以供魔法释放的消耗。能够储蓄更多的海水意味着更高的对魔法的控制能力，该控制能力关系到：释放一个魔法所需要的引导时间。代表魔法下限，决定感知能力、速率与掌控。
- 【意识海】：无边无际的沙海，压制水滴缩成沙粒。沙海的厚度可以被拓展，是能够承载活性元素多少的体现，和魔力流通的阻滞性，更高的阻滞性也让控制魔法的释放需要耗费更多精力。其中的沙粒就是活性元素能量，以供魔法释放的消耗。能够储蓄更多的沙粒意味着更高的对魔法元素的控制能力，该控制能力关系到：释放一个魔法所能达到的最低下限。代表魔法上限，决定能耗与威力。通过冥想拓展。

**冥想（Meditation）**：
不同于常规认识中的放空冥想，魔法冥想需要持续保持高度专注。

冥想步骤：【感知】→【塑想】→【构建】→【捕捉】→【明晰】/【俱现】，之后略过【构建】重复该过程。

- 【感知】：以第三人称感受自己的存在，在此视角感知肌肤附近的空气，由此感知魔法元素颗粒的存在
- 【塑想】：幻想魔法元素颗粒是任意一种"实物"，把想到的东西幻想在脑海
- 【构建】：当【塑想】到一个"实物"时，根据该"实物"可能出现的地方构建一个场景。如塑想一片叶子，则构建一片土地或树林，让其叶子可以被场景所承载
- 【捕捉】（也称【压制】）：维持【塑想】的"实物"向元素颗粒靠近，直至包裹魔法元素颗粒。期间【感知】与【塑想】需同时维持
- 【明晰】：维持包裹的同时为【塑想】的"实物"添加细节，让它从模糊的图像逐渐转为清晰，也意味着对包裹中的元素颗粒也有了更清晰的认知。之后把幻想的"物体"收回脑海，代表该元素颗粒被吸收进体内。结合【构建】形成精神海
- 【俱现】：为单个【明晰】的"实物"添加细节直至如同在现实中所见一样呈现在脑海中。当"实物"为完全真实时，该元素颗粒也从休眠状态转为【活性】。为容纳这种活性的元素，此时需要再次【构建】一个场景来容纳他们，且场景需要不相同。结合【构建】形成意识海

每一步都将筛去一大批法师学徒。一个被【明晰】与【俱现】在脑海的"实物"将被永久储存在脑海深处中，且可以被随时从脑海中调取，或在精神层面查看，乃至进入构建的场景中。首次完成后，法师学徒将被允许称为魔法师。

**感知详解（Perception Detail）**：
如何进入第三人称视角——基于睡眠中的"坠落感"：正常：睡觉→半睡半醒→坠落感→惊醒。在半睡半醒之间达成心流，以做到肉体沉睡、意识清醒，这个过程即是冥想的前提，也是【感知】——第三人称的感受。这种灵魂的失重很难适应，坠落感正来自于此刻意识脱离身体的漂浮感。尝试熟悉这种感觉直到不会被其惊扰。以保持这种第三人称的观测感，在这种状态下即可以感受到世界中存在的魔力。

为什么只有睡觉进入心流才能够进入这种视角：因为只有睡觉的这一刻最接近意识游离，而且没有大幅度的肢体动作。事实上还有一种相近的方法那就是冥想——传统的放空冥想不容易真的睡着还能让意识处于一个半睡半醒的状态，所以绝大多数人都会选择冥想来作为修炼的方法，久而久之冥想成为了感知魔法的代名词。相近的还有如阅读书籍、仰望星空等。

**释放魔法（Spell Casting）**：
初阶、中阶的绝大多数魔法都以能量释放为主——把精神海或意识海中贮存的魔法能量稍加控制的释放，期间使用感知约束能量产生各种效果。部分中阶魔法与高阶魔法才开始结合符文使用。此时符文作为魔法呈现的主体，而魔法能量主要起到供给能量的效果。

**元素外显影响（Element Manifestation）**：
当一个人的意识海足够强大，其中所蕴含的活性元素达到一定阈值，他的外显将会被魔法潜移默化的影响：
- 30%-90%：喜好被间接影响，使之更接近所蕴含元素的特性
- 40%-75%：毛发被间接影响，使之更接近所蕴含元素的颜色
- 65%-90%：瞳孔被间接影响，使之更接近所蕴含元素的颜色
- 75%-100%：性格被间接影响，使之更接近所蕴含元素的特性

**时间魔法**：
时间不属于魔法，是一种世界规则，属于符文。

**材料与炼金（Materials & Alchemy）**：
统合魔法材料、材料处理、炼金术为一套体系。材料是炼金的输入，炼金是材料的加工。

**材料品类**：
- 【素料】：仅能够转化魔法元素
- 【白料】：仅能够容纳魔法元素
- 【魔料】：能够转化魔法元素，还能容纳魔法元素

**材料属性**：
- 【亲和性】：-9~9级别。亲近魔法元素的效能高低，高亲和性使材料效果提升至多2倍。一种材料可以有多种不同的亲和性，且程度各不相同
- 【导魔性】：-9~9级别。传导魔法能量的效率高低，高传导性使材料在使用时需要更短的引导时间。如果导魔性为负，则作为道具时不能传导魔法能量
- 【含有元素】：材料包含哪些天然元素属性。绝大多数材料所含有的属性都非常复杂，平均约有五种左右。所含属性更多或更少都更稀有：11-10罕见 / 9-8-7-6-5-4常见普通 / 3-2-1罕见。日倾向的天然元素（电、火、光、草、雷）与月倾向的天然元素（风、暗、水、土、木、冰）相斥，不能同时出现在同一个【层级三】中

**材料等级计算**：(含有元素稀有度) + (亲和性 + 导魔性 × 0.5) + (材料品类)

**材料处理系统（Material Handling）**：
通用材料系统，适用于草药、矿物、生物掉落物、木材等一切材料，非草药学或炼金术专属：
- 辨认：识别材料种类，靠感知力/知识/经验
- 采集：正确时机、手法、工具，错误会损伤材料品质
- 特性：药用/毒性/元素亲和，对应炼金材料属性
- 炮制/预处理：晒干、研磨、发酵、蒸馏，改变材料状态供后续使用
- 储存：保质期、防腐、魔法保鲜
- 知识传承：师徒传授、书本文献记录

设计哲学：高自由度、可自我完善。不预设死规则（如根茎叶花固定药性），结果由材料特质组合自然涌现。体系内持续有新材料/新发现涌现并被记录，玩家/NPC 可自行定义新的加工方法融入体系，知识通过师徒/文献在文明中传播。

**炼金术：特性与层级（Alchemy: Traits & Layers）**：
材料含有【源质三】【前析三】【后析三】三种层级：
- 【源质三】：与生俱来的本源特性，总是处于【上浮】状态，其特性不会被加工改变
- 【前析三】：材料原有的特性，默认处于【下沉】状态，其特性可以被加工和炼制而改变
- 【后析三】：材料隐藏的特性，总是处于【下沉】状态，其特性可以被加工改变

特性即为一种魔法材料所拥有的效果，这些特性有着元素分类和日月倾向性，且分布在不同层级之间。通过加工与炼制来操作【上浮】的特性使之发生各种改变。

规则：
1. 特性可以在同一层级和不同层级重复
2. 未经过加工的材料，同一层级下不会出现重复特性
3. 不同层级的同一个特性，只要有一个被激活就视为都被激活，重复的特性可以累计效果即为等级
4. 上浮与下沉的状态仅说明能否被加工与炼制的操作影响。成品后所有特性都会生效
5. 在任何情况下被添加的特性都处于【上浮】状态
6. 相斥的元素不会出现在同一层级下，否则相互抵消
7. 在对同一个材料进行加工时同种手法不能连续，且分支不能重复
8. 只能用与材料主元素相斥的手法作为加工的第一步
9. 添加的元素特性若与现有元素特性相斥，则提升加工所需时长并消除现有的元素特性
10. 添加的元素特性与现有的元素特性，同属一种倾向则使现有元素特性转化为被添加的元素特性
11. 一旦离析，就不能再次加工

草药学/炼金术/材料加工均以此为统一底层。草药炼制复用炼金机制，叠加植物特质模块产出。

**炼金产物（Alchemy Outputs）**：
高自由度——不仅限于魔药/材料，可炼出武器、护甲、道具、饰品、机械造物等一切可想象产物。产物属性由投入材料特质 + 加工手法组合涌现，玩家/NPC 可自行实验发明新产物配方，知识通过文献/师徒传播。

**造物结构（Creation Structure）**：
武器/道具/造物为多部件拼装（如棍身、剑刃、机关、鞘）。结构设计由玩家主动决定，功能由部件组合决定。部件化设计同建筑/生物统一。

**符文刻录机制（Rune Engraving）**：
造物的自定义行为通过符文刻录实现——玩家在部件上刻录符文来定义特殊功能（右键切换形态、受击触发机关、条件激活等）。符文即造物的行为编程语言。刻录受符文类型（元素/视见/窥知）、材料导魔性、刻录精度影响。符文刻录造物可被修改/覆盖/剥离。

**锻造系统（Smithing）· 毛坯**：
待制作时详细设定。必须遵循既有设计哲学：
- 管线：材料处理（材料系统）→ 加工（炼金机制）→ 部件拼装（造物结构）→ 符文刻录（自定义行为）
- 铁匠角色、锻造技法（淬火/折叠/合金等）、锻造设施均由文明自然演化涌现，不预设
- 遵循主循环系统与分形系统模型（见 `SYSTEMS.md`）
- 高自由度、可自我完善：新技法/新材料组合可被实验发现并经师徒/文献传播

**契约魔法（Contract Magic）**：
非独立新系统，由现有体系自然支撑：魂符绑定（灵魂契约）、咒术魂咒（违约惩罚）、祈灵（神明契约）、符文刻录（条款书写）。契约双方可为：人与人、人与神、人与生物、人与异界存在。

**法术设计（Spell Design）**：
- 玩家侧：编译器模式。玩家亲手编排符文序列与阵结构，规则引擎做确定性校验（能耗/载能、元素相斥、结构合法性），校验失败即法术失效/爆炸。玩家通过冥想参悟、亲眼见识（视见符文）解锁符文。
- NPC 侧：涌现模式。需求驱动方向 + 在知识边界内随机探索符文序列 + 规则引擎筛选合法结果。NPC 的知识就是数据（探索过海洋→知识表加海符文），无需参悟体验。
- 规则引擎：确定性校验系统，检查元素倾向冲突、元素交互（逸散/消解/同化/侵蚀/驱散/瓦解）、能耗载能、阵结构合法性，计算稳定性/波动性/强度。玩家与 NPC 共用同一引擎，仅"谁生成候选物"不同。

**符文（Rune）**：
无读音，无固定写法。法师通过阅历和感知从思维混沌中"打捞"解析。符文需组合使用，类似编程逻辑。高强度的参悟符文会导致迷失——精神与意识瓦解。参悟过程："混沌的点排成线，后由线曲成圈"。

当一个符文被常人观察时，它既不能被阅读也不能被幻想，脑海中不呈现任何东西，这种失神会永久保持直到符文被移开或被外界影响。当一个符文被法师观察时，脑海中呈现一片混沌，这种状态可以借助魔法材料与道具来人为操控。

四种类别：
- 【基础符文】：包含数字与字母等基础结构的符文
- 【元素符文】：也称魔法符文，涵盖所有的魔法元素，是最常用的符文
- 【视见符文】：世间万物皆有所指，每一粒沙在世界框架中都有着一个独立的符文。世界的法则运行在符文之上，掌握符文即掌握世界运行的规则。若想深入的了解并运用每一个符文，需要从根本上去看见、去感受、去认识。如果一个内陆法师从未见过海洋，那么他就不能使用与之相关的符文。即魔法师在一定瓶颈之后大多会选择游历四方
- 【窥知符文】：探寻本质，追寻本源。能够认识到这种符文是窥见与知悉神的第一步

每个符文有三种倾向以生成不同结果：
- 【日】（横线）：亲和电、火、光、草、灵、圣光、雷、风暴、毁灭、神圣、生命、自然。每个日符文使魔法阵【强度】提高。日符文多于月符文时，依照差值提高【能耗】
- 【月】（竖线）：亲和水、土、风、暗、木、巫术、冰、毒、神秘、凋零、死灵、灾异。每个月符文使魔法阵【能耗】降低。月符文多于日符文时，依照差值降低【强度】
- 【混沌】（点）：亲和所有元素。若以日符文为主则所有混沌符文视为日符文；若以月符文为主则所有混沌符文视为月符文；若以混沌符文为主则所有混沌符文视为空符文

**魔法元素（Magic Elements）**：
26种元素——生命、神圣、圣光、灵、自然、光、雷、火、草、木、毁灭、电、空间、土、神秘、风暴、风、水、巫术、暗、灾异、毒、冰、凋零、死灵。各元素拥有独立特性（水≠冰，电≠雷，草≠木，毁灭≠灾异）。

元素分类：
- **基底元素（8）**：水、火、光、暗、草、土、风、电——自然存在的原始元素
- **复合元素（8）**：雷、圣光、灵、木、巫术、冰、毒、风暴——其中木、冰、雷可在自然界中存在，但本质属于复合元素
- **神性元素（8）**：生命、自然、神圣、神秘、毁灭、灾异、凋零、死灵——不可自然存在的神性力量
- **空间**：不属于以上三类，居于圆阵中心。纯元素/空间元素——充斥世界每一寸空间的无属性元素，是魔法能量的主要来源。其余元素根据自身依赖环境自然分布。特性：无性（可被轻易转化为任何元素，任何元素都将被缓慢同化回空间元素），不被消解/逸散/侵蚀/驱散/瓦解，不会失活。

**元素状态（Element States）**：
- 【休眠】：自然存在的元素的通常状态。自然存在的元素大多无规律的飘动。
- 【活性】：维持/增幅特性效果。保持活性使元素更容易被感知，使元素的特性效果增强。元素被操控着运动即活性，维持活性时产生元素波动。
- 【失活】：失去/降低特性效果。失去活性使元素更不易被感知，使元素的特性效果降低。通常状态下自然存在的元素和体内不被操控的元素即为失活状态。

**元素交互（Element Interactions）**：
- 【逸散】：元素长时间保持【活性】，不加以控制。最终【转化】为纯元素。
- 【消解】：元素长时间维持【失活】，不加以控制。最终【转化】为纯元素。
- 【转化】：由一种元素，自主转为另一种元素。
- 【激活】：由一种元素迫使另一种元素维持/增强【活性】状态、维持/增强【失活】状态。
- 【同化】：由一种元素，迫使另一种元素向自身【转化】。
- 【侵蚀】：由一种元素，迫使另一种元素【消解】。
- 【驱散】：由一种元素，迫使另一种元素【逸散】。
- 【瓦解】：由一种元素，迫使另一种元素？（原始定义未完成，待补。从既有用法看：使目标元素完整结构崩解，强于【侵蚀】/【消解】，是躁动性/相侵性/迸发性元素失控的后果）

**基底元素特性（Base Element Properties）**：

**【火】**
- 【侵化性】：总是不可控的维持【同化】状态
- 【放热性】：维持【活性】时释放温度
- 【相光性】：更容易【逸散】，且【逸散】时会转化为光元素
- 【躁动性】：有着更高的【活性】，形体难以约束，极易被感知且难以控制。两种不同的躁动性元素相互靠近会引发爆炸
- 【相侵性】：维持【活性】时，不可控的维持【侵蚀】状态。两种不同的相侵性元素相互靠近会使双方的侵蚀结果改为【瓦解】

**【水】**
- 【可塑性】：可以更容易的凝结成形态，且能穿透绝大多数实体
- 【留滞性】：不能【同化】其它元素，可以粘染在实体甚至其它元素上，融入其它元素使其【瓦解】
- 【适引性】：水元素互相吸引，凝聚的水元素难以被【转化/同化】且变得难以操控
- 【凝和性】：【活性】较低，容易被操控且难以被感知
- 【相侵性】：维持【活性】时，不可控的维持【侵蚀】状态

**【电】**
- 【摧解性】：本身【逸散】时使附近的元素【失活】
- 【簌烁性】：运动不能被干扰与阻挡，且只在运动时可见
- 【链絮性】：维持【活性】时相互排斥，非常容易【逸散】，极难操控。【休眠/失活】时相互吸引
- 【迸发性】：有元素系中最极端的速度，总是不可控的维持【瓦解】状态。除非接触实体或元素否则运动方向只能大概规束
- 【躁动性】：同火

**【土】**
- 【塑造性】：只能呈现为实体可见的，并且不会被【瓦解】
- 【嵌合性】：互相吸引，凝聚的土元素不容易【逸散】，变得难以操控（呈现为石）
- 【折离性】：在【失活/休眠】中，难以恢复【活性】（呈现为沙）
- 【排它性】：不容易被元素特性影响，难以被其他元素【瓦解/转化/同化/侵蚀/驱散】
- 【解融性】：被水元素【留滞性】影响后完全失去自身特性，获取与水元素相同的特性

**【风】**
- 【无形性】：没有形体，难以被肉眼察觉，能够穿越绝大多数物体
- 【流动性】：难以约束，总是保持运动永远不会在同一位置停留
- 【永息性】：永远保持【活性】且不会【逸散】
- 【裹缚性】：在运动时，可以附带实体或其它元素
- 【斥进性】：有着更快的速度，维持【活性】时更难被操控。运动的风会排斥行进路径的实体

**【草】**
- 【增活性】：极其不容易【失活】
- 【衍育性】：处于【活性】时还会把附近处于【失活】的其他元素【激活】
- 【溅生性】：在被【转化】或【瓦解】后，【消解】附近的元素并自我复制
- 【中和性】：不会对其他元素【瓦解/转化/同化/侵蚀/驱散】
- 【极息性】：在高温或高寒下【活性】降低

**【光】**
- 【神性】：只能自我【逸散】，被光元素影响的任何元素【逸散/消解】时会【转化】为光元素
- 【兼知性】：更容易感知到元素波动
- 【两斥性】：维持【活性】时，总是不可控的维持【驱散】状态。两种不同的两斥性元素相互靠近会使双方的特性结果随即覆盖

**【暗】**
- 【本源性】：任何元素都更容易【转化】为暗元素，暗元素不能被【转化】
- 【敛知性】：几乎不能被感知
- 【两斥性】：同光

**魔法阵（Magic Circle）**：
本质是符文组成的电路板。用途：集中供能、绕过吟唱、附魔道具、灵魂刻印。
三种触发类型：激发型（陷阱）、休眠型（道具）、崩解型（一次性卷轴）。

**魔法阵绘制（Magic Circle Drawing）**：
本体构成：
- 【眼】：由单个符文或完整的魔法阵组成，可为魔法阵的激活点，或阵外魔法能量的输入点。若眼的【稳定性】被破坏，将不能够主动汲取能量，且现有能量会持续【消解】
- 【核】：由单个符文或完整的魔法阵组成，可为魔法阵的激活点，或阵内魔法能量的汇聚点。若核的【稳定性】被破坏，将不能够主动释放能量，且现有能量将持续【逸散】
- 【阵轮】：用来约束魔法能量与符文能量使之不会【逸散】，提供最基础的稳定性，形成魔法阵主体。较难绘制，需要高度接近圆形
- 【阵骨】：用来容纳魔法阵的能量，使之不会因外界影响而【瓦解】，降低波动性，支撑魔法阵结构。阵骨可以代替阵轮使用，约束能力大大降低，魔法能量极易流失，且生效后即刻崩溃，但魔法阵的强度略微提高，适用于急迫的临时需求
- 【符文序列】：由任意数量的符文所构成的一组顺序排列，以此生成有效的魔法
- 【魔法纹路】：由任意勾勒的线条所连接起来的一整个魔法阵魔力流通的通道。细分：
  - 【导纹】：简单的刻画与绘制的纹路，链接法阵与符文，传导魔力流通的通道
  - 【抵纹】：随意的刻画与绘制的纹路，不产生任何效果，阻碍魔力流通的方向
  - 【魔纹】：繁杂的刻画与绘制的纹路，链接辅阵与主阵，传输符文序列的通道

纹路绘制手法：
- 【塑纹】：一种特殊的绘制手法，使纹路可以首尾相连，通常用于绘制阵轮。如果链接符文序列，则随着塑纹的引导重复生效
- 【载纹】：一种特殊的绘制手法，使纹路可以彼此交叠，通常用于绘制阵骨。如果链接符文序列，则随着载纹的引导依次生效
- 【启纹】：一种特殊的绘制手法，使纹路可以分叉延申，通常用于绘制套嵌。如果链接符文序列，则随着启纹的引导同时生效

特殊纹路：
- 【幻纹】：使用独特的材料，使纹路没有刻痕，只有在激活时才显现纹路
- 【饰纹】：使用独特的材料，描摹在【阵组、符文、纹路】之上。当被激活时根据饰纹材料产生不同颜色的立体呈现或放射光效。如果材料带有特殊激发效果也会生效（如亲和火元素的材料使魔法阵本身附带有火焰）

【节点】：不同纹路变化连接的过度点。当被传输的能量经过节点后将被记录，即便魔法阵结构有变动也不会影响正在传导的符文或序列。三种绘制方式：
- 日：无论符文倾向，整个符文序列都被视为日倾向
- 月：忽视日倾向的符文，月倾向符文被视为二倍
- 混沌：所有符文被视为空符文

【符文构成】：
符文是时间与空间具现的讯息，世间万物存在的密码，记忆与灵魂本质的解译。符文不能够被阅览和读取，只有完全呈现在记忆与意识中才能被清晰的感知到。符文又能够被记载和书写，只有完全呈现在记忆与意识中才能被完整的临摹出。

- 【魔符】：魔法阵的基础，由符文组成序列绘制在阵轮中，是魔法阵所能产出效果的释义与魔法能量的载体
- 【空符】：一种通常无效的符文，用于填充魔法阵使其更稳定。可以由【辅阵】连接纹路激活
- 【斥符】：一种逆向绘制的符文，仅能与斥符相互连接与激活，在常规魔法序列中激活将导致魔法阵崩溃
- 【缀符】：独立法阵之外的符文，由纹路连接至主阵之中，提供额外的能量承载上限与额外魔法效果。缀符不稳定易崩溃，但崩溃与否都不影响魔法阵本身的稳定性，适用于急迫的临时需求或新手
- 【魂符】：以自身的精神与意志潜力上限为代价，由实际物件或亡魂为载体代替符文效果绘制魔法阵。若如此做则魔法阵的稳定性等同于魔法师的精神与意志能力
- 【咒符】：使用特殊的材料构成的符文，该符文所组成的序列与魔法效果只对材料源头生效
- 【签符】：没有通解的独特符文，是魔法师根据自身经验与阅历所拟造出来的一次性符文。其中所指代的效果只有魔法师自己知道。以自身精神与意志的潜力上限为代价可以永久维持这种符文，也可以用魂符的方式由他人代替

法阵结构类型：
- 【辅阵】：独立于主阵之外的小型法阵，只根据符文序列或纹路顺序激活
- 【嵌阵】：包含在主阵之内的小型法阵，当主阵激活时同步激活。如果嵌阵绘制在主阵中心，主阵的魔法结果反而以嵌阵为主
- 【叠阵】：叠加在主阵之上的小型法阵，当主阵激活后，根据符文序列或纹路顺序激活
- 【离环】：绘制在主阵内的另一个阵轮，进一步约束魔法能量与符文能量，提升稳定性的同时作为保险存在。当外圈阵轮被破坏后依然能够约束阵中能量一段时间，避免魔法阵崩溃殉爆
- 【套嵌】：牺牲魔法阵稳定性在同一个主阵中绘制多个嵌阵的阵轮，节省占用空间，每个阵轮间都可以绘制不同的符文序列

绘制属性：
- 【稳定性】：规范绘制纹路、合理排版、或用高亲和的材料，使阵内的魔法能量相互维持平稳，不因外界因素而轻易导致崩溃
- 【波动性】：不规范的绘制、过量的填充、或留白都将导致魔法能量失衡，使阵内的魔法能量释出，严重可导致魔法阵的结构崩溃、完全释放能量、对周围造成灾难性后果
- 【强度】：单个法阵或魔法中所能造成的最大威力
- 【效能】：单个符文或魔法中所要需求的最大能量
- 【载能】：魔法阵整体所能够承载魔法能量的上限，意味着强度的上限。若载能高于能耗，依照差值略微提高强度
- 【能耗】：魔法阵中的符文序列所需求的最大能量。如果能耗高于载能，大幅度提高波动性，同时魔法阵无法生效
- 【导魔性】：传导魔法能量的效率高低，影响魔法阵的激活速率、传导速率。导魔性可以为负
- 【亲和性】：亲近魔法元素的效能高低，影响魔法阵的能耗需求、效能需求。亲和性可以为负

外部因素：
- 【绘制手法】：熟练的手法可以使魔法阵避免瑕疵，提高导魔性，降低波动性
- 【魔法材料】：合适的材料可以使能量间避免排斥，提高亲和性，提高稳定性


### 5.3 建筑

**建筑生命周期（Building Lifecycle）**：
多阶段建造（地基→框架→外墙→屋顶→室内，每阶段可见，可被打断）→ 完成 → 使用中 → 过时 → 拆除。另有损毁 → 修复的支线。布局可能不合理或过时，反映文明真实发展轨迹。出资方：NPC 个体自建、权力中心出资、城邦公共工程、玩家自建据点。建筑样式由文化演化、技术限制、地形适应、建材就近、功能分区自然决定。使用归属：私有继承、公建公用、废弃占领、改建转换。
_Avoid_: 建筑快照、静态建筑、统一建筑风格、预制建筑类型

**建筑部件化（Modular Construction）**：
所有建筑由部件拼装而成——墙体段、屋顶段、地板段、门、窗、柱、楼梯、基础件、家具。建造分六阶段：地基→框架→外墙→屋顶→门窗→内饰。每阶段可被外部事件中断，中断后后续阶段可能降级材质。拼装决策同时考虑实用性和外观（实用驱动/文化驱动/审美驱动/攀比模仿）。

建筑设计来源：匠人 NPC 设计（建筑质量取决于匠人技能）、模仿+变异（观察邻居→模仿结构→按自身条件微调）、文化模板（文明自沉淀的建筑传统）、玩家设计（亲自拼建筑蓝图）。
_Avoid_: 预制建筑类型


### 5.4 食物

**近精细远粗糙（Detail-on-Sight）**：
玩家视线内的食物系统走完整配方链（真实烹饪体验），视距外的文明自运转 NPC 粮食仅计算抽象资源池。

**食物生产链（Food Production Chain）**：
文明自主演化，全部阶段不需要玩家推动：
- 采集阶段：采摘野果、狩猎、捕鱼
- 农耕阶段：开垦农田、种植作物（小麦、水稻、蔬菜、水果）
- 畜牧阶段：驯养动物（鸡、猪、牛、羊），需先有驯化技术
- 加工阶段：磨坊磨面、屠宰分割、发酵酿酒
- 烹饪阶段：食材→配方→成品（玩家亲自上手层）
- 魔法农业：魔力灌溉加速生长、魔法保鲜、附魔农具

**烹饪体系（Cooking System）**：
基础配方固定（面包=小麦粉+水+烤炉），调料/配菜自由搭配影响属性加成。玩家通过实验/学习/文明传播解锁新配方。

**食物细节（Food Details）**：
- 保鲜/腐败：食材有保质期，受温度/储存方式影响
- 季节性耕作：播种→生长→收获周期，不同作物不同季节
- 粮食储存：粮仓、冰窖、魔法保鲜
- 食物分配：贫富饮食差异，经济地位影响食物质量
- 饥荒/荒年：作物歉收→粮价暴涨→社会动荡
- NPC 饮食偏好：文化禁忌/个人口味
- 农作物病害/虫害：影响产量
- 灌溉/水利系统：旱田/水田不同需求
- 发酵深度：酿酒/酱造有成熟周期
- 节日饮食：特定节日→特定食物传统


### 5.5 城建

**城建模式（City-building Mode）**：
NPC 自主建造 + 玩家可建议（请愿/投票）+ 玩家拥有建造权。混合驱动。

**城邦基础设施（City Infrastructure）**：
文明自主演化涌现，无需玩家推动：
- 道路：土路→石板路→铺装大道
- 水源：水井、引水渠、蓄水池
- 照明：火把→路灯→魔法灯
- 防御工事：木栅→石墙→塔楼
- 公共空间：集市广场、神庙、浴场、公园
- 卫生：排水沟、垃圾处理、公厕
- 特殊设施：城中城/观园（贵族大院/宫殿区）
- 城外农田

**城邦建筑类型（City Building Types）**：
- 生产设施：磨坊、铁匠铺、窑炉、伐木场、采石场、牧场
- 仓储：粮仓、军械库、仓库
- 交通：桥梁、港口/码头、驿站
- 行政：议会厅、法庭、监狱、税所
- 教育：学堂、学院、大学、图书馆
- 医疗：诊所、魔法治疗所
- 商业：旅店、商铺、集市摊位
- 宗教：教堂、祭祀台、祭坛
- 娱乐：酒馆、剧院、竞技场、澡堂
- 军事：兵营、瞭望塔、武器库
- 居住：贫民窟、中产民居、豪宅
- 水利：水渠、水车、水库
- 住所：旅馆、别墅、马厩
- 储藏：地窖、冰窖、保险库
- 魔法：炼金工坊、附魔工坊、魔力汇聚塔、传送阵、冥想室
- 金融：银行、金库、拍卖行
- 文化：博物馆、画廊、纪念碑、陵墓
- 社会服务：孤儿院、养老院、施粥棚
- 通讯：信使站、传讯塔
- 奢侈品：珠宝工坊、裁缝铺、香料铺
- 地下设施：下水道、地下通道、墓穴
全部建筑由部件拼装构成，非预制类型。

**城邦布局（City Layout）**：
功能区由自然生长（同行业聚集→自发形成街区）、权力中心干预（强制规划）、地形限制（河流→码头、山脚→矿区）、历史痕迹（旧城墙→环路、废墟→新房）共同决定。无统一规划，布局可能不规整。

城邦扩张方式：城墙外延（旧墙变内环，新建外环）、卫星城（城外新建定居点→可能后并入）、加密发展（人口密度增高、贫民窟、阁楼、地下室）、强制移民（人口输出→新殖民地）。
_Avoid_: 网格布局、统一规划


### 5.6 冒险

**任务（Quest）**：
由世界状态的供需缺口自然触发，每个城邦/文明对同类任务的称呼和接受度不尽相同。来源包括：NPC/城邦状态、文明发展阶段、玩家主动探索。

**任务触发条件（Quest Trigger）**：
- 资源阈值触发：粮食储量低于N天消耗→"寻找新农田"
- 人口压力触发：人口超住房容量→"扩建居住区"
- 外部威胁触发：野怪袭击频率超阈值→"清剿任务"
- 权力中心焦虑触发：感知到外部或内部威胁→主动发布任务
- 玩家能力匹配：任务难度与玩家当前能力挂钩

**任务竞争（Quest Competition）**：
任务非玩家独占——NPC 冒险者也可接取。玩家可能到达任务点发现已被其他 NPC 完成或正在进行中。需要抢在 NPC 之前完成任务或与 NPC 组队协作。

**任务失败界定（Quest Failure）**：
- 时限到期：任务有截止日期，超时即失败
- 目标被夺：NPC 冒险者在玩家之前完成
- 目标消失：救援对象死亡、清剿目标被其他文明消灭
- 委托人消失：发布任务的 NPC/权力中心垮台
- 玩家放弃/死亡
失败有后果：声望下降、委托人关系恶化、权力中心信任度降低、后续任务断档。

**任务报酬（Quest Rewards）**：
- 金钱/物资
- 声望/好感
- 装备/道具
- 土地/房产
- 权力：政治回报→进入权力中心
- 信息：NPC 独家秘密/世界情报
- 技能传授：委托人教你独门技艺

**任务类型（Quest Types）**：
- 讨伐：清剿怪物/强盗/敌对文明部队
- 收集：采集资源/材料/情报
- 护送：保护 NPC/商队/物资运输
- 探索：探明未知区域/遗迹/地下城
- 建设：参与城邦基础设施建造
- 外交：出使其他文明/传递信息/谈判
- 侦查：潜入敌对区域获取情报
- 研究：协助学院/魔法师完成研究项目

**连锁任务（Quest Chain）**：
任务可连锁——完成前置→解锁后续。玩家成功或失败均影响连锁走向。跨城邦/跨文明的连锁任务构成玩家个人剧情线。

**探索机制（Exploration Mechanics）**：
- 自由探索：未被文明控制的区域对玩家开放
- 遗迹探索：灭绝文明的废墟/地牢
- 地图迷雾：未探索区域隐藏，玩家逐步揭开
- 发现触发：踏入特定区域→触发事件/任务/剧情
_Avoid_: 随机任务池、任务面板


### 5.7 BOSS

**BOSS 类型**：
- 野外巨兽（独立于文明之外）
- 剧情节点（特定条件触发）
- 文明产物（文明发展孵化出的威胁或守护者）
- 自然天灾级（影响全文明的事件级存在）
BOSS 随世界演化自然生成（如魔法混血、物种演化产物）。

**野外巨兽来源（Wild Boss Origin）**：
- 物种演化产物：世界生成阶段迭代出的顶级掠食者
- 魔法混血/变异：魔力浓度高的区域普通生物突变为BOSS
- 传说级存在：半神/远古残留/封印解除，非演化产物
- 玩家触发：挖掘、探索、破坏封印→惊醒地下/封印生物

**文明产物来源（Civilization-born Boss）**：
- 魔法实验失控：符文研究→不可控造物
- 科技灾难：炼金/机械失控→蒸汽傀儡、炼金巨像
- 守护者反噬：文明自造的守护神/战争兵器失控
- 污染/诅咒：长期工业/魔法活动污染→诞生扭曲生物
- 信仰实体化：宗教/信仰累积到极致→具象为实体

BOSS 同样使用拼接实体模型。

**BOSS 据点（Boss Lair）**：
形式不限定——树、洞穴、废墟城市、海底深渊、火山口、废弃城邦等。据点本身就是环境叙事的一部分。

**BOSS 觉醒界定（Boss Awakening）**：
普通生物/实体如何转化为BOSS：
- 基因突变：低概率的生殖变异→后代个体远超同类
- 魔力洗礼：长期处于高魔力环境→身体异变→巨大化/魔法化
- 吞噬/累积：长期捕食同类或收集魔力→累积到阈值→突变
- 文明干预：实验/仪式/武器化→人造BOSS
- 自然事件：天灾/魔力风暴→环境压力催生
- 年龄累积：极长的存活时间→体型/力量线性累积→跨越临界点
_Avoid_: 固定刷新点、开局满世界跑


### 5.8 剧情

**剧情模式（Narrative Mode）**：
世界级主线大事件 + 每个文明/城邦的动态剧情线。玩家参与其中产生变数，最终走向取决于文明状态和玩家选择。
_Avoid_: 固定主线、线性剧情

**主线涌现（Main Plot Emergence）**：
世界生成阶段埋下伏笔种子（远古封印、大陆碰撞、魔力灾变等隐伏事件）。文明发展到特定阶段触发伏笔→引发全大陆级别危机/转折。不同文明对同一主线有不同立场和应对策略。主线事件是多交点的分叉网络，非单线剧本。玩家每次重生可能站在不同文明的立场经历同一世界大事件的不同侧面。


## 六、玩家

### 6.1 RTS

**玩家控制范围（Player Agency）**：
玩家可建设自己的据点（独立实体/城邦管辖内/从小到大多阶段混合），并在地位足够时影响文明层级决策。玩家是文明中的一员，而非全知操控者。
_Avoid_: 上帝视角、全局操控

**玩家据点（Player Settlement）**：
三种形态混合：
- 独立实体：玩家选地自建，完全自主管理招人
- 城邦内属地：在城中购地建屋，受城邦法律/税收管辖
- 渐进路线：从一间房→一条街→权力中心级别的影响力扩张

**玩家影响文明（Player Influence）**：
多路径并行：投票（城邦议会中的一票）、游说/贿赂（影响有投票权的人）、领导权力中心（成为权力中心头领→行使该中心决策影响力）、武力夺取（推翻权力中心→成为决策者）、声望驱动（声望够高→NPC 主动听从建议）。

**玩家可操作范围（Player Operations）**：
高自由度——税收调节、征兵/组建军队、外交（宣战/结盟/贸易谈判）、法律制定/修改、土地分配、公共工程建设、官员委任。但非一言堂——决策受权力中心动态权重制约，操作若违反权力中心利益可被抵制、架空、推翻。玩家同样面临权力中心拉锯和夺权风险。

**横幅提示（Banner Display）**：
可开关（默认开）。玩家进入文明辖区→横幅显示文明名称，进入城邦范围→横幅显示城邦名称。

**玩家死亡（Player Death）**：
走完整 NPC 死亡判定流程（身体属性降至阈值）。阶段一：过场动画——本地文明执行死亡仪式（葬礼/火化/海葬等，由文化演化决定）。阶段二：时间快进——观看上一世痕迹在世界中逐渐消散（建筑被他人占据或废弃、NPC 记忆中的自己淡化、遗产被继承或遗忘）。阶段三：轮回转生——以新身份降临世界。玩家仅可选择出身的文明，不可选具体出生点。高等文明可能生在贫民窟，低等文明可能生在富人家，身份由随机决定。
_Avoid_: 原地复活、身份保留、选择出生点
