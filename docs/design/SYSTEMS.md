# 主循环系统映射

> 平台：Forge Minecraft 26.3
>
> **本文档仅供参考**——是设计思路与架构映射，非严格规格。实际制作时可灵活调整。

**系统化原则**：万物皆可系统化，绝大多数设计都能纳入主循环模型。遇到本文档尚未系统化的部分，制作时请依据同一模型自行系统化——万物大体相似，套用五要素（组件 / 感知 / 需求 / 输出 / 频率）+ 运 + 内乱·外患 + 演化即可。

全模组只有一个主循环引擎。本文档把每个领域映射到该引擎，展示"万物皆此引擎的不同参数微调"。

## 主循环定义

```
感知（感知内外状态）
  → 评估（对比需求 / 目标 / 缺口）
  → 决策（选择响应）
  → 执行（消耗资源，产生输出）
  → 反馈（环境响应，状态更新）
  → 演化（长期：组合 → 筛选 → 传播）
```

**任何系统的定义只需五要素**：
1. **组件**：由什么组成
2. **感知**：感知什么
3. **需求**：被什么驱动
4. **输出**：能产生什么
5. **频率**：多久跑一次

**两个通用轴**：
- **运**：稳定度（该系统的健康）
- **内乱 / 外患**：失败模式

**时间尺度层级**（频率参数）：

| 频率 | 典型系统 |
|---|---|
| 每帧 | 物理、天体运动 |
| 每秒数次 | 个人即时反应 |
| 每分 | 个人短周期行为 |
| 每小时 | 疾病、局部事件 |
| 每游戏日 | 气候、城邦运营、经济 |
| 每游戏季 | 天道 |
| 每游戏年 | 文明、国运 |
| 每代 | 物种演化 |
| 每地质纪 | 大陆漂移 |

## 1. 物质 / 物理

### 1.1 系统定义

物质系统是世界的底层物理——26 种元素及其状态与交互构成万物基础。在这个世界里，元素不是静态的惰性物质，而是带"活性"状态的动态存在。元素系统即本世界的物理学。

### 1.2 组件

**26 种元素**
- 基底元素（8）：水、火、光、暗、草、土、风、电
- 复合元素（8）：雷、圣光、灵、木、巫术、冰、毒、风暴
- 神性元素（8）：生命、自然、神圣、神秘、毁灭、灾异、凋零、死灵
- 空间元素（1）：纯元素，充斥世界每一寸空间，魔法能量的主要来源

**元素状态**
- 休眠：自然元素的通常状态，无规律飘动
- 活性：被操控运动，特性增强，可被感知
- 失活：失去/降低特性效果

**元素特性**
每种元素有固有特性（如火：侵化性/放热性/相光性/躁动性/相侵性），详见 CONTEXT.md 基底元素特性表。

### 1.3 感知

- 元素之间的相互作用与特性触发
- 环境温度、压力
- 魔力场波动
- 相邻元素状态

### 1.4 需求 / 规则

- 元素交互规则：逸散/消解/转化/激活/同化/侵蚀/驱散/瓦解
- 元素特性规则：各元素的固有行为（相斥、吸引、复制等）
- 空间元素守恒：一切元素最终被缓慢同化回空间元素
- 同层相斥：日倾向元素与月倾向元素不能共存于同一层级

### 1.5 输出

- 元素状态变化（激活/失活/转化）
- 能量释放/吸收（热、光、力）
- 物质形态变化（凝结/逸散）
- 连锁反应（爆炸、侵蚀扩散）

### 1.6 频率

- 热区：实时
- 冷区：事件驱动（无事件不计算）

### 1.7 运 / 稳定度

元素分布平衡度。某区域元素失衡（如魔力过高、元素相斥冲突）→ 视为该区域物质层的低运。

### 1.8 失败模式

- 内乱：元素失控——躁动性元素碰撞爆炸、相侵性元素瓦解、场失衡
- 外患：异种元素入侵、空间元素被强制转化、法则变化

### 1.9 演化

元素本身不演化（是世界常量）。但元素的分布随地质演化、气候变化、文明活动（魔法工业、魔力开采）而改变。

## 2. 气候 / 气象水文

### 2.1 系统定义

气候是一个在球面拓扑上运行的大气-水体循环系统。它是主循环的实例：大气粒子格是"身体"，热力学平衡是"需求"，风与降水是"输出"。

### 2.2 组件

**大气粒子格（粗粒度）**
- 空间粒度：64×64 区块为一格
- 每格属性：
  - 温度（°C 映射值）
  - 气压（相对值）
  - 湿度（0-100%）
  - 速度向量（风向/风速）
  - 元素浓度（魔力及天然元素）
- 全星球约数百个格（依星球大小）

**水循环组件**
- 地表水：海洋、湖泊、河流
- 地下水：含水层
- 空中水汽：绑定在大气格中
- 冰雪：低温区固态水

**地形修正层**
- 海拔修正（气温随海拔递减）
- 山脉雨影（迎风坡降水、背风坡干旱）
- 海陆热力差（白天陆热、夜晚海热）
- 洋流（暖流/寒流影响沿岸）

### 2.3 感知

- 相邻格的温度/气压/湿度差
- 太阳辐射输入（纬度 × 季节 × 昼夜 × 云量）
- 地形阻挡与抬升
- 魔力浓度扰动
- 天体影响（如双星系统的辐射周期）

### 2.4 需求 / 规则

- 热平衡：温差驱动能量流动
- 压差平衡：高压流向低压
- 水汽平衡：蒸发 = 降水 + 径流 + 渗透
- 具体规则：
  - 热空气上升，遇冷凝结降水
  - 纬度决定基础温度带
  - 海拔每升高 100m 降温
  - 海陆温差驱动昼夜风向反转

### 2.5 输出

- 风（风向/风速）
- 降水（雨/雪/冰雹）
- 温度变化
- 极端天气：暴雨、暴雪、干旱、冰雹、风暴、飓风
- 魔法世界特有：魔力风暴、元素潮汐

### 2.6 频率

| 层级 | 频率 |
|---|---|
| 粒子级（粗） | 每游戏日推演一次 |
| 区域网格 | 每几游戏小时 |
| 逐格模拟（热区） | 实时 |

### 2.7 运 / 稳定度

气候稳定度：极端天气频率的倒数。长期干旱或风暴频发 = 低运 → 影响农业、文明稳定。

### 2.8 失败模式

- 内乱：局部气流紊乱 → 风暴、干旱、洪涝
- 外患：魔力风暴、陨石、天道干预、星系法则变化

### 2.9 演化

- 长期气候变化（冰期/暖期交替）
- 地形演变（板块漂移）改变气候带
- 文明活动影响（如魔法工业排放魔力污染 → 改变局部气候）

## 3. 天道

### 3.1 系统定义

天道是星球级/星系级的意志实体，是主循环在最高空间层级的实例。它不是一个具象的神，而是该层级万物状态的聚合意志——有性格、有目标、能干预。

### 3.2 组件

- 意识核心：天道的自我
- 性格：由星球/星系历史状态塑造（可能温和、可能暴烈）
- 状态感知网：对全层级万物的感知
- 干预手段：天灾、赐福、气运分配、伏笔埋设

### 3.3 感知

- 全星球/星系状态：生物量、文明活动、魔力浓度、生态平衡、法则运行
- 各道（人道/鸡道等）的状态
- 各文明的国运
- 外部威胁（星系天道、宇宙灾变）

### 3.4 需求 / 规则

- 核心需求：自我存续（星球即其身体，崩溃则死亡）
- 次要目标由性格决定：可能追求繁荣、平衡、战争、秩序等
- 干预需消耗自身气运，非无限
- 不能直接违反法则系统

### 3.5 输出

- 天灾（地震、火山、风暴、瘟疫）
- 赐福（丰饶、灵感、天才降生）
- 气运分配（影响国运/道）
- 伏笔埋设（为未来大事件埋种子）
- 对文明的态度变化

### 3.6 频率

- 每游戏季做一次全局评估
- 重大干预按需触发

### 3.7 运 / 稳定度

天道自身的健康 = 星球健康度。生态繁荣、法则稳定、文明克制 → 高运。生态崩溃、战乱遍野、魔法失控 → 低运。

### 3.8 失败模式

- 内乱：星球生态崩溃、法则失衡、自身性格极端化
- 外患：星系天道干预、外来入侵、宇宙灾变、被文明弑杀

### 3.9 演化

性格随星球历史塑造，极慢演化。经历剧变的星球天道可能"性情大变"。天道可能死亡（星球毁灭）也可能诞生（新宜居星球成熟）。

## 4. 物种演化

### 4.1 系统定义

物种演化是基因池系统，用特质模块的组合变异 + 环境筛选产出所有生物。它不模拟具体进化链，只跑主循环：变异 → 筛选 → 传播。

### 4.2 组件

**特质模块**（植物/动物/NPC 统一）：
- 体型（微型/小型/中型/大型/巨型）
- 运动方式（行走/飞行/游泳/掘地/攀爬）
- 食性（草食/肉食/杂食/食腐/噬魔）
- 防御机制（甲壳/鳞片/毛皮/速度/伪装/毒素）
- 社会性（独居/小群/大群/真社会性）
- 体温（恒温/变温/魔法恒温）
- 感知（视力/嗅觉/听觉/魔力感知）
- 生殖（卵生/胎生/孢子/魔力分裂）

每个特质模块内有细分参数。附加遗传属性：毛皮厚度、颜色、角/牙/翼形态等。

**基因池**
- 每个区域的物种基因池
- 跨代遗传的性状组合
- 突变率参数

### 4.3 感知

- 环境压力：气候（温度/降水）、食物分布、天敌、魔力浓度、地形
- 种群内部：繁殖压力、竞争
- 外部事件：灾害、文明活动

### 4.4 需求 / 规则

- 生存：获取食物、躲避天敌、适应气候
- 繁殖：找到配偶、繁衍后代
- 筛选规则：不适应的个体被自然淘汰（环境作为筛选器，不是禁止器）

### 4.5 输出

- 性状变化（新物种诞生）
- 种群数量与分布变化
- 生态位占据
- 与其他物种的互动（捕食/竞争/共生）

### 4.6 频率

- 每代一次（世界生成阶段压缩为快速迭代）
- 游戏阶段按实际繁殖周期

### 4.7 运 / 稳定度

物种存续度：种群规模 × 适应度 × 遗传多样性。

### 4.8 失败模式

- 内乱：基因退化、种群瓶颈、近亲衰退
- 外患：天敌、疾病、环境突变、文明捕杀、BOSS 出现

### 4.9 演化

本身即演化系统。长期产出：新物种、生态位分化、食物链重构、魔法生物诞生。

## 5. 植物

### 5.1 系统定义

植物是与动物统一特质体系的固定类群。它对接食物系统（作物）、炼金体系（药材）、材料处理系统（木材/草药）。植物不移动，其主循环的"执行"表现为生长与繁殖。

### 5.2 组件

- 植株本体：根、茎、叶、花、果（各部位可独立作为材料）
- 种子库：可传播的遗传载体
- 特质模块（与动物统一）：株型（草本/灌木/乔木/藤蔓）、生命周期（一年生/多年生/长生种）、繁殖方式（种子/孢子/扦插/魔力分裂）、果实类型（浆果/核果/荚果/翅果）、防御（刺/毒素/硬壳/共生蚁巢）、元素亲和、魔力产量、根系形态
- 魔法属性：元素亲和度、可提纯魔力的品种

### 5.3 感知

- 土壤养分与水分
- 阳光（光周期决定开花）
- 魔力浓度与元素分布
- 季节信号（温度/日照变化）
- 共生菌群信号

### 5.4 需求 / 规则

- 生长：积累生物量直至成熟
- 繁殖：开花、授粉、结实、传播
- 生存：抵御病害、虫害、气候压力
- 规则：光照/水分/养分/温度/魔力五要素决定生长速率；缺一即停滞或死亡

### 5.5 输出

- 生长（各阶段形态）
- 开花、结果、种子
- 蔓延（根系扩张、孢子扩散）
- 魔法植物：释放元素波动、发光、吸引/排斥生物、提纯魔力

### 5.6 频率

| 行为 | 频率 |
|---|---|
| 生长 | 每游戏日 |
| 繁殖 | 每季/每年 |
| 演化 | 每代 |

### 5.7 运 / 稳定度

存活度：种群规模 × 环境适配度。单一栽培的农田抗病力低（低运），多样化的原生植被高运。

### 5.8 失败模式

- 内乱：病害、虫害、基因退化
- 外患：气候灾害（干旱/霜冻）、动物啃食、人类砍伐、魔力污染

### 5.9 演化

与动物演化机制一致：特质模块 + 环境筛选。
- 杂交途径：自然授粉、人工授粉、嫁接、魔力诱导
- 驯化：野生采集 → 反复选育优良个体 → 多代稳定成驯化品种。驯化品种产量高、抗病强，但野外生存力下降

## 6. 个人 / NPC

### 6.1 系统定义

NPC 是主循环在个体层级的实例。它是世界中最精细的模拟单位——玩家、NPC、动物都共享此模型（动物是简化版）。

### 6.2 组件

- 拼接实体：头部、躯干、左右臂、左右腿、尾巴等子实体（独立血量/受击/脱落/再生）
- 属性：基本（姓名/性别/年龄）、身体（身高/体型/力量/敏捷/体质/颜值）、心智（智力/感知力/学识）、性格（七组对立维度）、爱好（加权兴趣表）、技能、关系、记忆、状态（饥饿/疲劳/心情/健康/精神压力）、经济（财产）、社交（声望/煽动力/领导力/口才）、驱动（野心/目标）、天赋（天赋/缺陷）、魔法维（元素亲和/精神海/意识海/符文知识/魔法阶段）
- 记忆：重要记忆完整存储 + 事件日志引用；低权重定期清除；重大事件永不遗忘
- 生命周期阶段：婴儿→儿童→青少年→成年→中年→老年

### 6.3 感知

- 五感（视力受部位损毁影响）
- 社交信息（关系值、传闻、权力中心动态）
- 魔法感知（精神海感知元素、感知符文波动）
- 环境（危险、天气、地标）

### 6.4 需求 / 规则

四层需求 + 魔法维：
- 生存：食物、水源、住所
- 安全：防御、治安
- 社会：交易、娱乐、信仰
- 发展：工具、科技、扩张
- 魔法维：与四层交织
需求缺口 → 驱动行为选择。缺口长期未满足 → 精神压力上升 → 低运。

### 6.5 输出

- 四层 AI 行为：
  - 即时反应层（寻路/战斗/逃跑/拾取/闪避/跟随等）
  - 短周期行为层（工作/饮食/睡眠/社交/修炼/教育等）
  - 长周期决策层（婚嫁/迁徙/转行/收徒/反抗/创立权力中心等）
  - 交互外壳层（对话/贸易/任务/情感表达，含 LLM 自由对话）
- 劳动产出（加入经济系统）
- 创造（法术设计/造物/建筑）

### 6.6 频率

| 层 | 频率 |
|---|---|
| 即时反应 | 逐帧~每秒数次（仅热区） |
| 短周期行为 | 几秒一次（仅热区） |
| 长周期决策 | 几分钟一次（全部 NPC） |
| 交互外壳 | 按需（当前交互对象） |

### 6.7 运 / 稳定度

个人运：健康 × 精神稳定 × 社会关系 × 财富地位的综合倾向。

### 6.8 失败模式

- 内乱：精神崩溃、疾病、欲望失控、伤势恶化、信仰崩溃
- 外患：攻击、灾难、诅咒、毒、经济破产、社会排斥

### 6.9 演化

- 一生内：属性增长（使用增长/年龄升降/教育加速/事件触动/天赋上限）
- 跨代：特质遗传（身高/体型/天赋倾向）
- 死亡：身体属性降至阈值（非固定年龄）；死后财产/知识/关系网转入继承与记忆系统

## 7. 家庭 / 社区

### 7.1 系统定义

家庭是主循环在社会最小层级的实例——由血缘和婚姻纽带连接的个人集合。社区是家庭的松散聚合。

### 7.2 组件

- 成员 NPC（含年龄/性别/健康状态）
- 共有财产（住宅、土地、工具、存款）
- 关系网（血缘、婚姻、邻里）
- 家族记忆（口传历史、荣誉、仇怨）
- 家族声望

### 7.3 感知

- 成员状态（健康/心情/安全）
- 邻里环境（治安/经济/声誉）
- 外部机会与威胁

### 7.4 需求 / 规则

- 成员福祉：家人安全、温饱、发展
- 血脉延续：婚嫁、生育、抚养
- 社会认同：家族声誉、社会地位

### 7.5 输出

- 互助（照护老幼、共享资源）
- 繁衍（婚配/生育/抚养）
- 婚嫁（与其他家庭联姻）
- 迁徙（举家迁移）
- 家族事业（传承的工坊/商铺/农田）

### 7.6 频率

- 每游戏日
- 重大决策（婚嫁/分家/迁徙）低频

### 7.7 运 / 稳定度

家运：成员健康 × 财富 × 家庭和睦 × 社会声誉。

### 7.8 失败模式

- 内乱：家庭矛盾、遗产纠纷、家暴、分家
- 外患：外部威胁、灾害、经济衰退、家族蒙冤

### 7.9 演化

家族兴衰周期、代际财富/技能/声誉传承、家族分支形成新家庭。

## 8. 权力中心

### 8.1 系统定义

权力中心是主循环在社会组织层级的实例——由需求催生、从社会群体中涌现的决策力量。制度不是预设的，而是多个权力中心动态权重拉锯的瞬时平衡。

### 8.2 组件

- 成员 NPC（领导层 + 普通成员）
- 资源与财产（资金、田产、工坊、武器）
- 影响力权重（动态值，随事件漂移）
- 内部治理结构（由该中心自身演化：长老制/推举制/世袭/军阶等）
- 名称（创始人名 / 性质名，如"铁骨锻炉会""银枝观星院"）

### 8.3 感知

- 城邦状态（资源、民情、治安）
- 其他权力中心的动向与权重
- 民众诉求与不满
- 外部威胁与机会

### 8.4 需求 / 规则

- 存续：不被其他中心吞并
- 扩张：提升自身权重与影响范围
- 践行职能：各自领域的目标（农会抓粮食、学院抓魔法、军头抓防务）
- 拉锯规则：议题由权重加权决策；权重变化由事件压力驱动（战争→军头权重涨，和平繁荣→商贾权重涨）

### 8.5 输出

- 决策与政策（税收、征兵、贸易）
- 委派（指派 NPC 转业、任命官职）
- 庇护（给予成员资源与保护）
- 拉锯（与其他中心的联盟/对抗/妥协）
- 长时效决议（沉淀后对外可抽象为"法律"）

### 8.6 频率

每游戏日评估权重与决策；重大决议低频触发。

### 8.7 运 / 稳定度

中心兴衰度：权重 × 内部凝聚力 × 资源基础。

### 8.8 失败模式

- 内乱：内部派系斗争、腐败、分裂
- 外患：其他权力中心打压、民众反抗、被吞并

### 8.9 演化

权重随事件漂移，权重跌到零即消亡（无预设生命周期）。新中心由需求催生（角色诞生 → 中心萌芽）。制度在拉锯中自然沉淀。

## 9. 城邦

### 9.1 系统定义

城邦是主循环在聚居层级的实例——NPC 生存与互动的空间容器，也是经济、建筑、权力中心运行的平台。

### 9.2 组件

- 人口（总数 + 年龄分布 + 技能分布）
- 资源池（粮食、木材、石料、魔力、金属等）
- 经济（产出能力、贸易路线、货币体系、市场价格、产业分布）
- 权力中心列表（各自权重与内部结构）
- 科技树 / 魔法树（节点进度 + 区间判断，非硬性解锁）
- 城邦间关系（多维交织：贸易依存/文化渗透/军事对峙/历史渊源/外交条约/资源互锁）
- 当前需求缺口列表
- 建筑列表 + 各自状态
- 长期决议（权力中心拉锯的持久化产物）

### 9.3 感知

- 内外局势（邻邦动向、战争威胁）
- 资源库存与缺口
- 民情（幸福度、忠诚、反抗苗头）
- 他城邦/文明的动态

### 9.4 需求 / 规则

- 稳定：治安、粮食、民心
- 发展：经济增长、技术推进、领土扩张
- 安全：防御工事、军事力量
- 规则：资源分配由权力中心拉锯决定；人口/资源/建筑相互制约

### 9.5 输出

- 建造（基础设施与建筑）
- 贸易（与其他城邦/文明）
- 外交（结盟、宣战、谈判）
- 战争（动员、出征）
- 税收与公共工程
- 移民（人口输出/引入）

### 9.6 频率

每游戏日结算；重大事件（宣战/灾难）即时触发。

### 9.7 运 / 稳定度

城运：资源储备 × 民心 × 权力中心平衡度 × 防御能力。

### 9.8 失败模式

- 内乱：权力斗争、叛乱、瘟疫、饥荒、阶级冲突
- 外患：战争、围城、灾害、经济封锁、被吞并

### 9.9 演化

扩张（城墙外延/卫星城/加密/强制移民）、衰落、制度自然演变、可能被并入他邦或灭绝成遗迹。

## 10. 文明

### 10.1 系统定义

文明是主循环在最高社会层级的实例——多个城邦聚合而成的高级社会单元，拥有中心城邦、道、国运。

### 10.2 组件

- 城邦集合（含中心城邦）
- 道（该文明的集体气运载体）
- 国运（含国运形象——被多数人认同的图腾/神/符号）
- 文化（价值观、习俗、建筑传统、语言）
- 科技/魔法树（全文明进度）
- 历史档案（书面记录层）

### 10.3 感知

- 其他文明（关系、威胁、机会）
- 天道态度
- 环境与资源
- 内部民情（各城邦状态）

### 10.4 需求 / 规则

- 存续：不被吞并/灭族
- 扩张：领土、人口、影响力
- 繁荣：经济、文化、技术
- 文化认同：维系共同体的凝聚力
- 规则：国运由国民幸福度/生活水平/安定度/文化认同加权得出；国运反向影响发展速度/稳定/战争胜负/人才涌现

### 10.5 输出

- 外交（条约、结盟、宣战）
- 战争（国战级动员）
- 文化传播（影响邻邦）
- 技术扩散（被邻邦学习）
- 主线事件参与（剧情分叉网络中的立场选择）

### 10.6 频率

每游戏月评估；游戏年结算国运。

### 10.7 运 / 稳定度

国运（详见 CONTEXT.md 国运条目）。

### 10.8 失败模式

- 内乱：分裂、内战、政变、文化解体
- 外患：战争、入侵、经济制裁、天灾、天道惩罚

### 10.9 演化

制度演化、兴衰周期、可能灭绝（建筑变遗迹最终消失）。文明灭绝后其知识可能通过文献/幸存者/邻邦部分保留，也可能永久失传导致科技退行。

## 11. 星系 / 天体

### 11.1 系统定义

星系是主循环在宇宙尺度的实例——恒星、行星、星际物质按引力规则运行的集合。它同时承载法则系统（不同星系可有不同法则）。

### 11.2 组件

- 恒星（红矮星/黄矮星/蓝巨星/黑洞等）
- 行星（宜居/非宜居）、卫星、小行星带
- 星际物质（尘埃、气体、魔力场）
- 法则配置（该星系启用的法则集合）
- 星系天道（若形成）

### 11.3 感知

- 引力场与质量分布
- 能量分布（恒星光度、魔力浓度）
- 星体间的轨道关系

### 11.4 需求 / 规则

- 引力平衡、能量最低原理
- 恒星生命周期规律
- 宜居带计算（恒星类型 → 轨道距离 → 温度）
- 法则约束（缺失法则的领域无法发展）

### 11.5 输出

- 天体运动、轨道
- 辐射与潮汐（影响行星气候）
- 星际物质流动
- 孕育/毁灭宜居星球

### 11.6 频率

- 天体运动：每帧（热区）/ 宏观按游戏年
- 星系演化：每地质纪

### 11.7 运 / 稳定度

星系稳定度：轨道稳定性 × 恒星健康 × 法则平衡。

### 11.8 失败模式

- 内乱：恒星坍缩、轨道崩溃、超新星爆炸
- 外患：外部星体干扰、黑洞吞噬、星系碰撞

### 11.9 演化

恒星生命周期的自然推进、星系形成与演化。星球子法则可在演化中孕育（星系法则之外的法则一旦在多数星球出现即升格为根本法则）。

## 12. 疾病

### 12.1 系统定义

疾病是主循环在病原体层级的实例——以宿主为资源的繁殖-传播系统。统一覆盖植物、动物、NPC。

### 12.2 组件

- 病原体类型：细菌、病毒、魔力污染、诅咒
- 传播途径：空气、接触、水、食物、魔力
- 潜伏期、症状、致死率参数
- 变异率

### 12.3 感知

- 宿主状态（体质、免疫力）
- 传播途径可得性（人口密度、卫生条件）
- 环境条件（温度、湿度、魔力浓度）

### 12.4 需求 / 规则

- 繁殖、传播
- 规则：宿主体质对抗病原体强度；卫生条件影响传播率；魔法可干预；文明医疗水平影响治愈率

### 12.5 输出

- 感染（宿主症状）
- 传播（扩散到新宿主）
- 变异（新变种）
- 宿主属性变化（体质下降、精神压力上升）

### 12.6 频率

每小时结算（热区）；冷区按事件驱动。

### 12.7 运 / 稳定度

病原体存续度（能否持续繁殖传播）。低存续即被扑灭。

### 12.8 失败模式

- 内乱：免疫系统抵抗、病原体自身过快致死宿主导致传播中断、耐药性演化（对病原体是"演化"不是失败）、种群瓶颈
- 外患：药物、隔离、魔法治疗、卫生改善

### 12.9 演化

变异 → 传播成功者存活 → 新变种。文明可通过研究建立免疫/疗法，病原体则演化出耐药性，形成军备竞赛。

## 13. 经济 / 市场

### 13.1 系统定义

经济是主循环在资源流通层级的实例——资源、商品、货币、交易者在供需规则下流动。

### 13.2 组件

- 资源与商品（含加工品）
- 货币 / 等价物体系（从以物易物自然演进）
- 交易者（NPC 商人、行会、城邦）
- 贸易路线（陆路/水路/魔法通道）
- 市场（城邦集市、拍卖行）

### 13.3 感知

- 供需缺口
- 价格信号
- 政策（税收、禁令）
- 运输成本与风险

### 13.4 需求 / 规则

- 供需平衡
- 利润驱动（商人逐利）
- 价格由供需浮动；短缺→涨价→刺激生产/进口
- 货币信用影响交易效率

### 13.5 输出

- 价格波动
- 贸易流（商品流向）
- 生产调整（NPC 转行、作坊扩建）
- 财富分配变化

### 13.6 频率

每游戏日结算。

### 13.7 运 / 稳定度

经济景气度：供需匹配 × 货币信用 × 贸易畅通。

### 13.8 失败模式

- 内乱：通胀、垄断、泡沫、贫富分化
- 外患：战争、封锁、灾害、货币失信、贸易路线断绝

### 13.9 演化

货币体系自然演进（以物易物→金属货币→纸币→魔法凭证）、产业升级、贸易网络扩张或收缩。

## 14. 符文 / 法术

> https://www.bilibili.com/video/BV1fK42147eA
> https://www.bilibili.com/video/BV1uw4m1D7cX
> https://www.bilibili.com/video/BV1zVY3ezEgS
> https://www.bilibili.com/video/BV1XE4peVEYn

### 14.1 系统定义

符文/法术是主循环在魔法结构层级的实例——符文序列与法阵结构在规则校验下运行，产出魔法效果。

### 14.2 组件

- 符文（四类：基础/元素/视见/窥知；三倾向：日/月/混沌）
- 特殊符（魔符/空符/斥符/缀符/魂符/咒符/签符）
- 法阵结构（眼/核/阵轮/阵骨/纹路/节点/辅阵/嵌阵/叠阵/离环/套嵌）
- 绘制属性（稳定性/波动性/强度/效能/载能/能耗/导魔性/亲和性）

### 14.3 感知

- 魔力输入（来自施法者或环境）
- 外界扰动（结构冲击）
- 符文倾向与元素亲和状态

### 14.4 需求 / 规则

- 稳定运行：满足校验规则（能耗 ≤ 载能、无斥符错位、元素不冲突）
- 规则引擎确定性校验（详见 CONTEXT.md 法术设计条目）
- 玩家：编译器模式（手动设计，规则校验）
- NPC：涌现模式（需求驱动 + 知识边界内随机探索 + 筛选）

### 14.5 输出

- 魔法效果（按魔法类型：威能/防护/治愈/咒术/奇变）
- 施法反馈（成功/失败/爆炸/反噬）

### 14.6 频率

激活时按需运行；持续型法阵（如护盾）持续结算。

### 14.7 运 / 稳定度

稳定性（绘制质量 × 材料亲和 × 结构合理性）。波动性过高即低运。

### 14.8 失败模式

- 内乱：波动性过高 → 结构崩溃/殉爆
- 外患：眼被毁（无法汲取能量）、核被毁（无法释放能量）、阵轮破坏

### 14.9 演化

法术设计变异 → 规则校验筛选 → 传承传播（学徒/文献/学院）。法术流派 = 一组验证过的、互相兼容的、可传承的法术集合。

## 15. 造物 / 装备

### 15.1 系统定义

造物是主循环在部件组合层级的实例——武器/道具/造物由部件拼装 + 材料特质 + 符文刻录共同构成。

### 15.2 组件

- 部件（棍身/剑刃/机关/鞘等，多部件拼装）
- 材料特质（亲和性/导魔性/含有元素/源质/前析/后析）
- 符文刻录（定义自定义行为）
- 结构设计（玩家/匠人主动决定）

### 15.3 感知

- 使用者指令（右键/受击/条件触发）
- 环境触发条件

### 15.4 需求 / 规则

- 功能实现（结构完整、符文刻录有效）
- 规则：材料特质决定属性涌现；符文刻录决定行为逻辑；结构决定形态与功能

### 15.5 输出

- 形态切换（如棍中剑拔出）
- 特殊效果（附魔、机关、条件激活）
- 属性加成/减益

### 15.6 频率

触发时按需。

### 15.7 运 / 稳定度

结构完整度 × 符文刻录完好度 × 材料状态。

### 15.8 失败模式

- 内乱：部件损坏、符文刻录失效、材料劣化
- 外患：外力破坏、魔法腐蚀、被掠夺

### 15.9 演化

设计组合（部件+材料+符文）→ 实战筛选 → 匠人传播。高自由度：可炼出一切可想象产物，知识通过文献/师徒传播。

### 15.10 锻造系统（毛坯）

待制作时详细设定。锻造是造物系统的职业化应用（同建造、炼金下游），必须遵循：
- 管线：材料处理 → 加工（炼金机制）→ 部件拼装 → 符文刻录
- 铁匠角色/锻造技法/锻造设施由文明演化涌现，不预设
- 遵循主循环系统与分形系统模型
- 高自由度、可自我完善（新技法可被实验发现并传播）

## 16. 建筑

### 16.1 系统定义

建筑是主循环在空间结构层级的实例——由部件拼装的、有生命周期的功能空间。

### 16.2 组件

- 部件（墙体段/屋顶段/地板段/门/窗/柱/楼梯/基础件/家具）
- 建造阶段（地基→框架→外墙→屋顶→门窗→内饰）
- 出资方（NPC 个体/权力中心/城邦/玩家）
- 使用状态（完成/使用中/过时/拆除/损毁/修复）

### 16.3 感知

- 环境（气候、地形）
- 使用者需求
- 出资方经济状况变化

### 16.4 需求 / 规则

- 功能实现、结构完整
- 拼装决策兼顾实用性与外观（实用驱动/文化驱动/审美驱动/攀比模仿）
- 建造可被外部事件中断；中断后后续阶段可能降级材质
- 六阶段建造，每阶段有资源需求、施工 NPC 数量要求、工期

### 16.5 输出

- 遮风挡雨、功能空间
- 反映文明发展轨迹的布局（可能不合理、过时）

### 16.6 频率

建造时按阶段推进；日常维护；生命周期变化（使用→过时→拆除）。

### 16.7 运 / 稳定度

建筑完好度（结构完整 × 维护状况）。

### 16.8 失败模式

- 内乱：年久失修、结构老化、内部火灾
- 外患：灾害损毁、战争破坏、被占领

### 16.9 演化

风格随文化演化；模仿+变异（观察邻居→模仿结构→按自身条件微调）；文化模板沉淀；改建转换（铁匠铺→酒馆）。

## 17. 权力中心之间的拉锯（跨系统交互）

### 17.1 系统定义

这不是独立系统，而是多个权力中心（系统 8）之间的交互场——它们彼此拉锯形成的动态平衡就是"制度"。

### 17.2 组件

- 复数个权力中心（各自权重/资源/成员）
- 议题（税收/战争/律法/资源分配）
- 联盟与对抗关系
- 民众（被争取的对象）

### 17.3 感知

- 彼此的权重与动向
- 议题相关的利益格局
- 民众情绪可被利用的缝隙

### 17.4 需求 / 规则

- 各自影响力最大化
- 拉锯规则：议题按权重加权决策；中心间可结盟/对抗/妥协；权重随事件压力漂移
- 拉锯可能演化为政变、分裂、清洗

### 17.5 输出

- 决策结果（政策出台）
- 联盟/对抗格局变化
- 制度沉淀（长期稳定的拉锯结果 → 抽象为法律）
- 政变/清洗/分裂

### 17.6 频率

每游戏日。

### 17.7 运 / 稳定度

整体政治稳定度：权重分布均衡度 × 民众满意度。

### 17.8 失败模式

即城邦层面的内乱/外患：内乱=派系火并/政变；外患=外部势力介入。

### 17.9 演化

制度自然沉淀（长决议→法律）。拉锯格局随文明发展阶段漂移（如战争时代军头独大，和平时代商贾崛起）。

## 跨系统传导关系

```
物质 → 气候 → 植物 → 物种 → 个人 → 家庭 → 权力中心 → 城邦 → 文明 → 天道
  ↑                                                                      ↓
  ← ← ← ← ← ← ← ← 反馈（干预/筛选/环境改变） ← ← ← ← ← ← ← ← ← ← ←
```

- **上行**：底层系统的状态聚合为上层系统的输入（个体健康→家庭→城邦→国运）
- **下行**：上层系统对下层施加影响（天道干预→气候→生物；国运→经济→个人）
- **横向**：同层系统相互竞争/协作（道与道、城邦与城邦、文明与文明）
- **所有传导都遵循主循环**：感知→评估→决策→执行→反馈→演化

## 代码要求（实现规范）

基于"一个主循环引擎 + 各系统参数表"的架构，代码必须满足：

### 统一接口
- 所有系统实现同一套标准接口（主循环的感知/评估/决策/执行/反馈/演化钩子）
- 系统之间只通过定义好的事件与数据契约通信，不直接依赖内部实现
- 新增一个系统 = 实现标准接口 + 注册参数表，零改动引擎

### 模块化与复用
- 复用优先：能参数化解决的绝不复制代码
- 部件化：生物/建筑/造物/法阵的部件体系共享同一套组合基础
- 特质模块（生物/植物）统一实现
- 主循环引擎、事件总线、记忆系统、时间调度等基础设施单独成模块

### 公私有序
- 公共 API 与内部实现严格分离
- 每个模块只暴露必要的接口，内部状态不外泄
- 模块依赖单向，不允许循环依赖

### 简洁干净
- 命名清晰、职责单一
- 无冗余代码、无死代码
- 复杂逻辑必须有对应文档注释

### 分类整齐
- 包/目录结构按系统分类，命名一致
- 系统代码、数据定义、配置分层清晰
- 跨系统的通用能力（运/内乱外患/演化循环）归入核心基础设施层
