# Adventurers 0.1.0 — 基础可玩原型

这是供协作开发和试玩使用的**预发布版本**，并非两份设计文档中全部功能的完成版。此版本从 PR 开发分支的交付提交构建；发布 Release 不代表该 PR 已合并到 main。

## 安装

- Minecraft **26.3**
- Forge **66.0.9**
- Java **25**

下载 `adventurers-0.1.0.jar`，放入客户端和服务器的 `mods` 目录。`SHA256SUMS` 提供文件完整性校验。当前没有额外动画库或在线 AI 服务依赖。

进入世界后等待文明生成，使用 `/advent civilizations` 查看文明，使用 `/advent join <文明编号> born` 加入。右键冒险人手记查看指引。完整的安装、指令和源码构建说明见 [README](https://github.com/xzh-minecraft-server/Adventurers/blob/v0.1.0/README.md)。

## 当前可以体验

- 六阶段模拟框架，简化的气候、生态、人口、城邦生产、建设、疾病、市场与知识演化。
- 三种玩家出身、文明加入、居民交互、基于城邦需求的物资任务和真实背包交付。
- 元素观察、冥想、符文序列编译，以及攻击、防护、治疗、净化四类施法效果。
- 城邦附近有限数量的居民外壳和分阶段建筑呈现。
- 带格式校验、原子写入和备份的模拟存档，以及管理与诊断指令。

## 验证与限制

Linux 云环境构建成功；**17 项核心验证、4 项真实 Forge 服务器测试通过，均无失败或跳过**。服务器测试覆盖初始化、保存恢复的一致性、实际治疗与冷却、物资交付和居民呈现。

尚未执行交互客户端画面检查、长期多人压力测试和其他操作系统验证。GitHub Actions 的远端结果请查看仓库 Actions 与关联 PR。

尚未实现的主要内容包括：真实球形世界与无缝位面、完整四层 NPC AI、身体与社会关系系统、LLM 对话、深度文明治理及外交战争、完整魔法与炼金玩法、动态剧情和星际 BOSS。当前实际地形仍为原版地形，居民使用原版村民外壳。

接续开发请阅读 [逐项实现范围](https://github.com/xzh-minecraft-server/Adventurers/blob/v0.1.0/docs/IMPLEMENTATION.md)、[架构说明](https://github.com/xzh-minecraft-server/Adventurers/blob/v0.1.0/docs/ARCHITECTURE.md) 和 [验证记录](https://github.com/xzh-minecraft-server/Adventurers/blob/v0.1.0/docs/VALIDATION.md)。
