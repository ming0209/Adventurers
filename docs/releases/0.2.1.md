# Adventurers 0.2.1 — 星球世界生成

本次开发预发布把地理模型接入真实 Minecraft 区块，提供三种星球大小、地形约束的文明落点、边缘跨界与手持星球图。它仍是完整设计的一部分；NPC 社会关系与知识传承、探索护送任务、炼金装备将按既定顺序继续开发。

此版本从 PR 开发分支的交付提交构建。发布 Release 不代表 PR 已合并到 main。

## 安装与体验

需要 **Minecraft 26.3 / Forge 66.0.9 / Java 25**。下载 `adventurers-0.2.1.jar`，替换客户端和服务器 `mods` 目录中的旧版 JAR，避免同时安装两个版本。`SHA256SUMS` 用于校验文件完整性。

新建世界时选择“冒险人星球（小 / 中 / 大）”。东西周长分别为 2,304 / 4,608 / 9,216 格，两极间距为相应周长的一半。专用服务器首次建档前设置 `level-type=adventurers:planet_small`（或 `planet_medium` / `planet_large`），`level-seed` 控制种子。

- 板块抬升和沉积侵蚀形成陆地、山地；汇水网络形成河道与湖盆。真实区块包含气候群系、地下洞穴、熔岩、矿化以及原版植被与生物。
- 文明选址检查陆地、坡度、温湿度和资源；初次出生搜索从干燥陆地开始。
- `/advent atlas` 领取星球图，观察生态、城邦与灭绝城邦；`/advent geography` 查看当地地理与基准气候。
- 东西跨界回到另一侧；过极点改变经度和南北方向。载具、乘客与货物保持一起。
- 等待文明涌现后，使用 `/advent civilizations` 和 `/advent join <文明编号> born` 体验原有文明、任务与符文玩法。

## 兼容性

先备份整个世界。0.1.0 世界可以继续载入，保存时由格式 1 升级为格式 2，保留城邦坐标、玩家身份与进度。已有世界保持原版地形；新星球地形需要新建世界。旧版模组不能读取升级后的格式 2，回退须恢复升级前的整个备份。

同一星球的种子、大小和地形算法版本固定。下界、末地保持原版。

`v0.2.0` 的远端验证未通过，未发布 Release；本次修复居民区块就绪与落点检查后使用新标签交付，不覆盖旧标签。

## 验证与当前限制

25 项核心验证通过；8 项 Forge GameTest 分别在普通预设和实际星球预设中通过，均无失败或跳过。覆盖地形与高度图、预设编解码、陆地出生搜索、带货载具跨界、地图持久索引及更新、旧档迁移，以及原有任务和法术回归。GitHub Actions 对标签提交重新构建和测试，成功后才发布附件。

跨界目前采用坐标传送，尚无无缝视野；原版装饰、结构与玩家方块没有跨界镜像同步。地形在生成时固定，地图的生态/文明更新不等于实时板块漂移或地形重塑。持续地质演化、文明附近预生成、局部天气、反向重力和多位面穿透仍未完成。未进行交互客户端画面检查、长期多人压力或其他操作系统验证。
